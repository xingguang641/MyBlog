# 拓扑排序基本原理

**拓扑排序** 是针对有向无环图（Directed Acyclic Graph，简称 DAG）的一种排序方法，其核心目标是在满足所有先后约束的前提下，将图中的顶点排列成一个线性序列。该排序并非任意排列，而是要求所得顺序能够完整反映图中蕴含的依赖关系，从而保证逻辑或执行上的正确性。

具体而言，若图中存在一条有向边 $u \rightarrow v$ ，则该边表示顶点 $u$ 在逻辑或时间上必须先于顶点 $v$ 。因此，在任何合法的拓扑序中，顶点 $u$ 都必须排在顶点 $v$ 之前。拓扑排序正是通过对所有这类有向约束的统一处理，构造出一个不违背任何约束条件的全局顺序。

从数学角度来看，拓扑排序刻画了偏序关系的一种 **线性扩展** 。在许多实际问题中，元素之间往往只存在部分先后关系，而并非完全可比；拓扑排序的作用正是在这些局部约束的基础上，将偏序关系扩展为一个全序，使问题能够以线性结构的形式加以分析和处理。

由于偏序关系本身通常并不唯一，拓扑排序的结果也不要求唯一。当图中存在多个互不依赖的顶点时，它们在拓扑序中的相对位置可以自由调整，从而产生多种不同但同样合法的排序结果。这一特性使得拓扑排序在建模并行任务或可交换步骤时具有较高的灵活性。

需要注意的是，拓扑排序存在的前提是图中不含有向环。一旦图中出现有向环，便意味着某些顶点之间存在相互依赖或循环依赖，从而导致先后关系自相矛盾。在这种情况下，无法构造出满足所有约束的线性序列，拓扑排序也就不存在。

## 拓扑建模分析

从本质上看，拓扑排序所处理的核心对象是 **偏序关系** 。在建模问题时，我们并不需要刻画元素之间所有可能的相对关系，只需提取那些 **不可违背的先后约束** 。如果能够准确描述这些约束，就可以将原问题转化为一个有向无环图，并通过拓扑排序得到符合要求的线性顺序。

在构建拓扑图时，关键原则是：**仅对 “必须在前” 的关系建边** 。若某个元素 $u$ 的执行结果会影响元素 $v$ ，并且这种影响在逻辑上不可被绕过，则应建立一条有向边 $u \rightarrow v$ ；而对于可以通过其他元素间接表达、或本质上并不存在直接依赖的关系，则无需额外建边。采用这种最小化约束的建图方式，既能保证正确性，也能避免引入冗余依赖。

以区间覆盖问题为例加以说明。设有一个长度固定的数组，初始时所有元素均为 $0$ 。接下来按照编号 $1 \sim n$ 的顺序，依次选择若干子区间，并将对应区间内的值刷为当前编号。不同操作之间可能存在覆盖关系，从而形成潜在的先后约束。

假设操作 $1$ 的作用区间被操作 $2$ 覆盖了一部分，而操作 $2$ 的作用区间又被操作 $3$ 完全覆盖。此时，从最终结果来看，操作 $1$ 中被覆盖的部分并非直接受操作 $2$ 的影响，而是最终被操作 $3$ 所覆盖；换言之，操作 $2$ 并未在这些位置上留下任何 “可观察的痕迹” 。因此，在依赖关系的建模中，操作 $1$ 实际上只需要受操作 $3$ 约束，与操作 $2$ 并不存在必然的先后关系。

在这种情况下，只需在拓扑图中建立一条有向边 $1 \rightarrow 3$ ，而不必额外加入 $1 \rightarrow 2$ 或 $2 \rightarrow 3$ 等冗余约束。通过这种方式提炼出的依赖关系，能够更准确地反映问题的本质结构，也为后续的拓扑排序与分析提供了更清晰的基础。

# 偏序排列拓扑问题

拓扑排序的本质，是在一个由偏序关系所约束的集合中，构造出一个满足所有约束条件的线性排列。换言之，拓扑排序并不是在 “排序大小” ，而是在 **将偏序关系扩展为全序关系** ，从所有合法的线性扩展中选取任意一个可行解。这里关注的并非元素之间的数值关系，而是它们在逻辑或操作上的先后约束。

因此，只要问题中的对象之间存在明确的先后限制，且这些限制满足偏序关系的基本性质（自反性、反对称性与传递性），就可以将问题自然地抽象为一张 **有向无环图（DAG）**，并通过拓扑排序来求解。在这一建模过程中，节点表示对象本身，有向边则刻画对象之间 **必须被遵守的先后关系** ，而是否存在合法解则对应于图中是否存在环。

在实际问题中，这类偏序关系并不局限于传统意义上的 “先做 A 再做 B ” 。例如，在整除关系中，若 $a \mid b$ ，则可以认为 $a$ 在 $b$ 之前；在比较运算中，若已知 $a < b$ ，同样构成一种顺序约束。这些关系本身并不要求给出完整顺序，只要它们之间不存在逻辑上的矛盾，**就能够被统一纳入拓扑排序的框架中进行处理** 。

从这一角度看，拓扑排序并不是某类特定题目的专属工具，而是一种通用的 **偏序问题求解框架** 。理解这一抽象，有助于在面对看似零散、杂乱的约束条件时，迅速识别其背后的偏序结构，并将原问题转化为一个 **可验证、可构造、可判定合法性的图论模型** 。

## 求解戳印序列

[题目链接](https://leetcode.cn/problems/stamping-the-sequence/description/)

### Problem Statement

你想要用小写字母组成一个目标字符串 `target` 。 

开始的时候，序列由 `target.length` 个 `'?'` 记号组成。而你有一个小写字母印章 `stamp` 。

在每个回合，你可以将印章放在序列上，并将序列中的每个字母替换为印章上的相应字母。你最多可以进行 `10 * target.length`  个回合。

举个例子，如果初始序列为 "?????" ，而你的印章 `stamp` 是 `"abc"` ，那么在第一回合，你可以得到 "abc??" 、"?abc?" 、"??abc" 。（请注意，印章必须完全包含在序列的边界内才能盖下去）

如果可以印出序列，那么返回一个数组，该数组由每个回合中被印下的最左边字母的索引组成。如果不能印出序列，就返回一个空数组。

例如，如果序列是 "ababc" ，印章是 `"abc"` ，那么我们就可以返回与操作 "?????" -> "abc??" -> "ababc" 相对应的答案 `[0, 2]` 。

另外，如果可以印出序列，那么需要保证可以在 `10 * target.length` 个回合内完成。任何超过此数字的答案将不被接受。

### Constraints

- $1 \leq stamp.length \leq target.length \leq 1000$
- `stamp` 和 `target` 只包含小写字母

### Input

输入包含两行：

- 第一行是一个字符串，表示 `stamp` 。
- 第二行也是一个字符串，表示 `target` 。

> $stamp$
> 
> $target$

### Output

输出若干个整数表示印章需要戳印的位置及顺序。

### Sample Input 1

```txt showLineNumbers=false
abc
ababc
```

### Sample Output 1

```txt showLineNumbers=false
0 2
```

### Sample Input 2

```txt showLineNumbers=false
abca
aabcaca
```

### Sample Output 2

```txt showLineNumbers=false
3 0 1
```

## 题目要点解析

这是一个典型的 **覆盖关系建模的拓扑排序问题** 。我们把每一个可能的戳印位置视为一个节点，通过分析不同戳印之间的覆盖依赖关系，来确定戳印的先后顺序。设印章长度为 $m$ ，目标串长度为 $n$ 。所有合法的戳印位置为：

$$
0, 1, 2, \ldots, n - m
$$

位置 $i$ 对应一次戳印，覆盖区间 $[i, i+m-1]$ 。

对于每一个戳印位置 $i$ ，将 $stamp$ 与 $target[i \ldots i+m-1]$ 逐位比较。若在某个位置上字符不相等，则说明该位置的字符必须先被其它戳印覆盖后，当前戳印才能生效。因此，这些不匹配的位置对应了对其它戳印的依赖关系。我们用 “不匹配字符数” 作为该戳印节点的入度。入度为 $0$ ，表示该戳印可以直接作为 **最后一次戳印** 执行。

以 `"aabcbc"` 和 `"abc"` 为例，在位置 $0$ 比较 `"aab"` 与 `"abc"`，有 $2$ 个字符不匹配，因此位置 $0$ 的戳印入度为 $2$ ；在位置 $1$ 比较 `"abc"` 与 `"abc"`，完全一致，因此位置 $1$ 的戳印入度为 $0$ ，它一定可以作为最后一步戳印。

在完成所有戳印位置的入度初始化后，对这些节点执行拓扑排序。每次取出一个入度为 $0$ 的戳印位置，视为执行该戳印，并将其覆盖区间内的字符 “清除” 。对于所有覆盖到这些字符的位置，对应戳印节点的入度减 $1$ ；若某个戳印节点的入度因此变为 $0$ ，则将其加入队列。

需要注意的是，拓扑排序得到的顺序是从 “最后一次戳印” 到 “最早一次戳印” 的逆序，因此在输出答案时需要将结果数组反转。如果最终无法将所有戳印节点纳入拓扑序列，说明存在无法满足的依赖关系，目标字符串无法构造，应返回空数组。

# 塔扬缩点拓扑问题

在有向图相关的问题中，很多约束并不直接构成一张有向无环图，而是可能包含环结构。此时，直接进行拓扑排序往往不可行，因为环的存在意味着顺序约束之间存在相互依赖。为了解决这一问题，通常需要先对图进行结构上的简化。

具体而言，对于一张弱连通的有向图，可以先对其进行强连通分量分解。由于强连通分量内部的任意两个节点都可以相互到达，在偏序意义下它们无法再被区分先后顺序，因此可以将每一个强连通分量整体收缩为一个节点。经过这一缩点过程后，原图必然被转化为一张 **有向无环图（DAG）**。

一旦图结构被化简为 DAG，原本复杂的约束关系就转化为了明确的偏序关系，此时便可以自然地引入拓扑排序及其相关算法，对缩点后的图进行处理。无论是判定可行性、构造一种合法顺序，还是在 DAG 上进行动态规划，拓扑序都提供了一种统一而高效的处理框架。

因此，在涉及弱连通、有向环以及先后约束的综合问题中，**强连通分量缩点 + 拓扑排序** 往往是一种十分常用且通用的解题思路。它通过先消除不可区分的环结构，再在宏观层面处理剩余的偏序关系，使得原本难以直接处理的问题变得结构清晰、易于分析。
