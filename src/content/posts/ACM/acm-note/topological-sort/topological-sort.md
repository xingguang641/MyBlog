# 拓扑排序基本原理

**拓扑排序** 是针对有向无环图（Directed Acyclic Graph，简称 DAG）的一种线性排序方法。其核心目标是在满足图中所有先后约束的前提下，将顶点排列成一个确定的序列。在这种排序中，若图中存在一条有向边 $u \rightarrow v$ ，则表示顶点 $u$ 在逻辑或执行顺序上必须领先于顶点 $v$ 。拓扑排序通过对这些有向约束的统一处理，构造出一个不违背任何局部依赖关系的全局顺序，从而保证了任务执行或逻辑推导的正确性。

从数学角度来看，拓扑排序刻画了偏序关系的一种 **线性扩展** 。在实际问题中，元素之间往往只存在部分先后关系，而非完全可比；拓扑排序的作用正是在这些局部约束的基础上，将偏序关系扩展为一个全序，使问题能够以线性结构的形式加以处理。由于满足约束的路径可能存在多条，拓扑排序的结果通常并不唯一。当图中存在多个互不依赖的顶点时，它们在序列中的相对位置可以自由调整，这种灵活性使得拓扑排序在建模并行任务或可交换步骤时表现得游刃有余。

需要注意的是，拓扑排序存在的前提是图中 **不含有向环** 。一旦图中出现环路，便意味着某些顶点之间存在循环依赖，导致先后关系在逻辑上自相矛盾。在这种情况下，无法构造出任何满足约束的线性序列。因此，拓扑排序不仅是一种排序工具，也常被作为检测有向图是否存在环路的关键手段。通过尝试构建拓扑序，算法可以直观地判断系统是否存在逻辑死锁或循环引用的风险。

## 拓扑建模分析

拓扑建模的核心在于对 **偏序关系** 的精确提取。在建模过程中，我们无需刻画元素间所有可能的相对位置，只需聚焦于那些 **不可违背的先后约束** 。通过将逻辑上的先后顺序转化为有向图中的边定向，原问题便能转化为一个有向无环图（DAG）。这种建模本质上是利用图论结构来承载逻辑依赖，从而利用 DAG 的拓扑性质，将复杂的网状约束梳理为有序的线性执行序列。

在构建拓扑图时，应遵循 **最小化约束原则** ，即仅对 “必须在前” 的关系建边。若元素 $u$ 的结果直接影响 $v$ 且该影响不可绕过，则建立有向边 $u \rightarrow v$。以区间覆盖问题为例，若操作 $1$ 的区间先后被操作 $2$ 和操作 $3$ 覆盖，但最终观测到的结果仅受操作 $3$ 决定，那么在依赖建模中，操作 $1$ 实际上仅受操作 $3$ 的约束。此时只需建立 $1 \rightarrow 3$ 的边，而无需引入 $1 \rightarrow 2$ 等冗余依赖。这种去冗余的建图方式能使问题的底层结构更加清晰，避免算法陷入无效的约束检查中。

通常拓扑排序仅适用于有向无环图，但当有环图存在 **步数限制** 等单调维度时，可以通过分层思想将其转化为 DAG。由于每经过一条边步数必然递增，状态无法回溯到过去，这种单调性有效打破了原图的环路。这个转化常与[分层图最短路](https://xingguang641.com/posts/acm/acm-type/shortest-path/#分层图最短路问题)挂钩：通过将节点 $u$ 拆分为 $(u, k)$（表示第 $k$ 步到达点 $u$ ），并将原图边 $u \rightarrow v$ 映射为 $(u, k) \rightarrow (v, k+1)$ ，原本复杂的有环图被拉平为多层 DAG。在这种建模下，每层间仅存在单向跨层边，使得我们能够结合拓扑排序或线性动态规划，高效解决带约束的路径优化问题。

# 偏序排列拓扑问题

拓扑排序的本质，是在一个由 **偏序关系** 所约束的集合中，构造出一个满足所有约束条件的线性排列。换言之，拓扑排序的核心并不在于简单的 “大小比较” ，而是在于 **将偏序关系扩展为全序关系** ，从所有合法的线性扩展中选取一个可行解。这种处理方式关注的并非元素之间的数值绝对值，而是它们在逻辑、操作或因果维度上的先后约束。

只要问题中的对象之间存在明确的先后限制，且这些限制满足偏序关系的基本性质（自反性、反对称性与传递性），就可以将问题自然地抽象为一张 **有向无环图（DAG）**。在建模过程中，节点代表对象个体，有向边则刻画对象之间 **必须遵守的先后准则** 。通过这种图论转化，原问题是否存在合法解，便等价于判定图中是否存在环路。若无环，则说明该偏序系统是自洽的，可以构造出合法的线性序列。

从这一角度看，拓扑排序是一种通用的 **偏序问题求解框架** ，其应用范围远超传统的任务调度。例如，在数论的整除关系中，若 $a \mid b$ ，可视为 $a$ 领先于 $b$ ；在复杂的逻辑推导中，已知 $a < b$ 同样构成顺序约束。理解这一抽象视角，有助于在面对零散、杂乱的约束条件时，迅速识别其背后的偏序结构，并将问题转化为一个 **可验证、可构造、可判定合法性** 的标准图论模型。

## 求解戳印序列

[题目链接](https://leetcode.cn/problems/stamping-the-sequence/description/)

### Problem Statement

你想要用小写字母组成一个目标字符串 `target` 。 开始的时候，序列由 `target.length` 个 `'?'` 记号组成。而你有一个小写字母印章 `stamp` 。在每个回合，你可以将印章放在序列上，并将序列中的每个字母替换为印章上的相应字母。你最多可以进行 `10 * target.length`  个回合。

举个例子，如果初始序列为 "?????" ，而你的印章 `stamp` 是 `"abc"` ，那么在第一回合，你可以得到 "abc??" 、"?abc?" 、"??abc" 。（请注意，印章必须完全包含在序列的边界内才能盖下去）

如果可以印出序列，那么返回一个数组，该数组由每个回合中被印下的最左边字母的索引组成。如果不能印出序列，就返回一个空数组。例如，如果序列是 "ababc" ，印章是 `"abc"` ，那么我们就可以返回与操作 "?????" -> "abc??" -> "ababc" 相对应的答案 `[0, 2]` 。

### Constraints

- $1 \leq stamp.length \leq target.length \leq 1000$
- `stamp` 和 `target` 只包含小写字母

### Input

输入包含两行：

- 第一行是一个字符串，表示 `stamp` 。
- 第二行也是一个字符串，表示 `target` 。

> $stamp$
> 
> $target$

### Output

输出若干个整数表示印章需要戳印的位置及顺序。

### Sample Input 1

```txt showLineNumbers=false
abc
ababc
```

### Sample Output 1

```txt showLineNumbers=false
0 2
```

### Sample Input 2

```txt showLineNumbers=false
abca
aabcaca
```

### Sample Output 2

```txt showLineNumbers=false
3 0 1
```

## 题目要点解析

本题的核心挑战在于处理 **盖章过程中的覆盖与重叠** 。由于后盖的印章会覆盖先盖的字符，正向推导印章顺序非常困难，因此我们采用一种 **逆向还原的思维**：尝试将 `target` 字符串逐步还原为初始的问号状态。每一次逆向盖章相当于找到一个当前区间，其非通配符部分与 `stamp` 完全匹配。我们将这些匹配位置视作已解决的局部并转化为通配符，表示它们在正向操作中可以被更晚的操作覆盖，从而消除了当前位置对这些字符的依赖。

为了系统化处理这种覆盖依赖，我们将每一个可能的戳印起始位置视为图中的一个 **节点** 。对于每个位置 $i$ ，其覆盖范围为 $[i, i+m-1]$ ，若该区间内某个字符与印章对应位置不匹配，则说明该字符必须由其他戳印来完成最终定型。在此建模下，每个戳印位置的 **入度** 被定义为该区间内当前与印章不匹配的字符数量。入度为 $0$ 的节点意味着该位置的所有字符要么已经匹配，要么已被其他逆向操作变为通配符，因此它可以作为当前还原步骤的合法候选。

在执行过程中，我们首先初始化所有戳印位置的入度并建立字符索引与位置的映射。初始入度为 $0$ 的位置首先入队，每从队列取出一个位置执行逆向戳印，便检查该区间内尚未处理的字符，并令所有覆盖这些字符的戳印位置入度减 $1$ 。一旦某个位置入度归零，说明其约束已消除，随即具备执行条件。最终得到的序列是正向盖章顺序的 **倒序排列** ，若执行完所有操作后 `target` 已完全转化，则翻转序列输出，否则说明存在循环依赖，目标序列无法构造。

# 塔扬缩点拓扑问题

在处理有向图约束问题时，许多场景下的依赖关系并不直接构成有向无环图，而是往往包含复杂的环路结构。由于环的存在意味着顶点之间存在逻辑上的循环依赖，这使得直接进行拓扑排序变得不可行。为了打破这种僵局，通常需要先对图进行结构化的简化，利用 Tarjan 算法或 Kosaraju 算法将图中的每一个强连通分量（SCC）识别出来。在强连通分量内部，任意两个节点都可以实现相互到达，这在偏序意义上意味着它们处于同一优先级，可以被视为一个整体。

缩点的核心操作是将识别出的每个强连通分量收缩为单个超节点，并保留不同分量之间的原始边。经过这一转换，原图中所有的环路都被封装进了超节点内部，而超节点之间留下的边则构成了一张严格的 **有向无环图** 。这种从微观节点到宏观分量的视角切换，成功地将原本混乱的循环约束转化为了清晰的先后顺序。此时，原本难以直接处理的复杂网络被精炼成了具有单向流动性的层次结构，为后续的逻辑分析奠定了坚实的拓扑基础。

一旦图结构被简化为 DAG，我们便可以顺理成章地引入拓扑排序及其关联算法。无论是通过拓扑序来判定整体约束的可行性，还是在缩点后的图上结合动态规划求解最长路径、最优权值等问题，拓扑序都提供了一个稳定且高效的处理框架。在涉及弱连通性与有向环的综合算法题中，**强连通分量缩点与拓扑排序的结合** 已成为一种标准范式。它通过先行消除不可区分的环结构，再在宏观层面梳理剩余的偏序关系，使得原本杂乱无章的约束变得结构透明且易于计算。
