# 活动安排贪心问题

活动安排问题是区间贪心算法中最为典型的代表模型。这类问题的核心挑战在于，当多个活动在时间或空间上存在重叠（即冲突）时，如何通过一套高效的选择规则，从集合中筛选出满足特定目标的子集。无论是追求 **参与任务数量的最大化** ，还是实现 **资源覆盖成本的最小化** ，贪心算法都通过在每一个决策点做出局部最优的选择，试图推导出全局的最优结果。

区间决策的本质是一场关于 **端点位置与单调性** 的精密博弈。所有有效的区间贪心策略，其底层逻辑都紧紧围绕着起止点的重叠、包含或相邻关系展开。通过对活动的开始时间或结束时间进行有序排列，我们实际上是在为一个混沌的集合注入 **决策序列感** 。例如，在经典的活动安排场景下，按照 **结束时间从小到大** 排序被证明是最优的：优先选择最早结束的活动，能为后续尚未安排的活动留出尽可能多的时间窗口，确保了每一次选择都基于对后续生存空间最大化的考虑。

为了确保贪心策略的正确性，通常引入 **交换论证法** 作为逻辑基石。这种证明方式通过假设一个理想中的全局最优解，并尝试在决策点上将其替换为当前的贪心选择。由于贪心选择（如最早结束的活动）在时间上不晚于原最优解中的任何活动，这种替换不仅不会破坏后续约束，反而可能创造出更优的 **边界条件** 。通过不断的等效交换，可以证明全局最优解最终能够转化为贪心解。这种逻辑上的完备性，使得我们在面对更复杂的区间覆盖或选点问题时，依然能够坚定地执行那一套经过数学验证的选择规则。

# 田忌赛马贪心问题

在贪心算法的实际建模中，田忌赛马类题目的破局点在于建立一套基于 **单调性** 的匹配机制。这种机制要求我们将双方的资源，即马匹实力，进行从小到大的有序排列，其本质是为了在扫描过程中构建一个 **单调增长的竞争力池** 。通过这种有序化处理，我们实际上是在为己方的每一匹马寻找一个 **最优生存空间** 。这种策略确保了我们在处理实力较弱的马匹时，能够以最小的代价试探出对方的防御边界，从而实现资源利用率的精准掌控。

这种匹配逻辑的核心在于 **待比赛区的动态维护** 。当己方的某一匹马进入决策视野时，它会首先在对方的序列中划定一个 **可选范围** ，即所有当前能够战胜的对手。将这些潜在的对手放入待比赛区，本质上是在进行一种 **决策降维** 。此时，原本复杂的全局对阵被简化为了在局部候选池中的二次挑选。根据题目对 “总得分” 或 “胜场数” 的不同侧重，我们可以贪心地选择待比赛区中价值最大或者实力最强的马匹进行对冲。这种分层决策的逻辑，确保了我们在每一轮的取舍中，都能在满足 **边界条件** 的前提下，为后续更强的马匹保留更优质的对阵组合。

这种 “先筛选再精选” 的贪心策略，深刻体现了 **双序列匹配** 的优越性。通过这种双重过滤，我们实际上剔除了那些无效的对阵尝试，将资源消耗锁死在最具性价比的区间内。这种逻辑不仅适用于传统的赛马问题，在处理诸如 “带时限的任务调度” 或 “多重限制下的资源分配” 时，这种 **基于有序预处理的候选池管理** 依然是最为稳健的。这种经过 **数学淬炼** 的匹配规则，正是将感性的策略直觉转化为高性能算法代码的桥梁。

# 合并果子贪心问题

合并果子是贪心算法中关于 **权值累加优化** 的经典模型。问题的场景通常是：地上有 $n$ 堆数目不一的果子，每次只能将其中任意两堆合并成一堆，合并消耗的体力等于两堆果子的重量之和。目标是求出将所有果子合并成一堆所消耗的最小体力。

这一问题的贪心策略非常直观：**每次都选择当前所有果子堆中重量最小的两堆进行合并** 。通过不断重复这个过程，直到只剩下一堆果子为止。这种策略的本质是构造一棵哈夫曼树（Huffman Tree），让重量较小的果子堆尽可能处于树的深层，从而增加其参与合并的频次；而重量较大的果子堆则靠近根节点，减少其被重复累加的次数，最终达到全局代价最小。

这种贪心选择的正确性在于，合并过程产生的总代价等于所有初始果子堆的重量与其在合并树中深度的乘积之和。为了使总和最小，权值越大的元素其对应的深度（即被合并的次数）必须越小。这符合排序不等式的基本逻辑：通过在每一步都消除当前最小的两个负担，我们有效地防止了较大权值在后续步骤中被反复计算，从而确保了每一步的决策都为全局最优解铺路。

在实现层面，为了高效地获取当前最小的两堆果子，通常使用 **小根堆** 作为核心数据结构。每次从堆顶取出两个最小值，合并后再将新生成的堆重量重新压入堆中。这种方式避免了每次合并后重新排序的巨大开销，将时间复杂度从 $O(n^2)$ 降低到了 $O(n \log n)$ ，使得算法能够处理规模庞大的数据集合。
