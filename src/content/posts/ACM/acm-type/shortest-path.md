# 最短路径算法原理

在图论问题中，**最短路径问题** 是一类极其基础而重要的研究对象。给定一张带权图，我们通常希望在众多可能的路径中找到一条总代价最小的路径。根据问题规模、图的结构以及边权的性质不同，人们设计出了多种求解最短路径的算法，例如单源最短路中的 Dijkstra 算法、Bellman–Ford 算法及其优化 SPFA，以及用于求解任意两点之间最短路的 Floyd 算法。这些算法在思想上各不相同，但本质上都是通过不断更新路径信息，逐步逼近最优解。

从算法设计的角度来看，最短路径问题同时体现了 **贪心思想** 与 **动态规划思想** 两种重要范式。例如 Dijkstra 算法通过贪心策略不断确定当前最短的节点距离，而 Bellman–Ford 与 Floyd 算法则更明显地体现了动态规划的思想，通过不断进行状态转移来更新最优值。理解这些算法时，如果仅仅记住代码实现往往是远远不够的，更重要的是理解它们背后的建模方式和适用条件。

因此，在接下来的内容中，我们将从算法原理出发，依次介绍几种经典的最短路径算法，并分析它们的核心思想、适用范围以及时间复杂度。通过这种方式，可以更系统地理解不同最短路算法之间的联系与区别，从而在实际问题中选择合适的算法解决对应的最短路径问题。

## Dijkstra 算法

Dijkstra 算法是一种用于求解 **单源最短路问题** 的经典贪心算法。给定一个带权图和源点 $s$ ，算法的目标是计算从 $s$ 到图中所有其他点的最短路径长度。算法维护一个数组 $dist[v]$ 表示当前已知的从 $s$ 到 $v$ 的最短距离估计，并使用一个优先队列按照距离从小到大选择尚未确定最短路的节点。初始时 $dist[s] = 0$ ，其余点为无穷大。每次从优先队列中取出距离最小的节点 $u$ ，此时可以认为 $dist[u]$ 已经是最终的最短距离，然后利用 $u$ 去松弛所有与其相邻的边，即尝试用 $dist[u] + w(u, v)$ 更新 $dist[v]$ 。这一过程不断重复，直到所有点的最短距离都被确定。整个算法的核心就是 **不断贪心地确定当前距离最小的节点，并利用它更新其他节点的距离** 。

Dijkstra 算法的核心正确性来自一种贪心性质：当某个节点 $u$ 被从优先队列中取出时，当前记录的 $dist[u]$ 一定已经是最短路径长度。直观理解是，如果存在一条更短的路径到达 $u$ ，那么这条路径必然经过某个尚未确定的节点，而该节点的距离应该更小，因此应该先被算法取出，从而在更早的步骤中更新 $u$ 。这种推理成立的关键前提是 **路径代价在扩展过程中不能减少** ，否则就可能在之后发现更短的路径，从而破坏贪心策略。因此，Dijkstra 本质上依赖一个重要条件：**路径长度必须随着路径扩展单调不下降** 。

从更抽象的角度看，最短路问题可以视为一种动态规划。设一条路径的代价为 $f(P)$ ，如果从某个状态 $A$ 通过一条边权 $w$ 扩展到状态 $B$ ，则有转移关系：

$$
f(B) = F(f(A), w)
$$

例如在普通最短路中，路径代价就是边权之和，此时转移函数为 $F(x, w) = x + w$ 。Dijkstra 算法实际上就是按照 $f$ 的大小顺序逐步确定这些状态的最优值，因此算法是否适用完全取决于转移函数 $F$ 的性质。

首先需要满足的是单调性。由于算法依赖贪心策略，路径代价在扩展时 **必须保持不下降** ，也就是：

$$
F(x, w) \geq x
$$

否则可能出现路径在加入新边之后反而变得更短的情况，从而使得之前已经确定的节点被后来更新，破坏算法的正确性。在普通最短路中，$F(x, w) = x + w$ ，因此要保证 $x+w\geq x$ ，就必须满足 $w \geq 0$ 。这也是为什么 Dijkstra 算法不能处理带负权边的图。

其次需要满足的是 **无后效性** ，或者说转移函数对状态值的单调性。如果存在两个状态 $A$ 和 $B$ ，且 $f(A) \leq f(B)$ ，那么在经过同一条边权 $w$ 扩展后，也必须保持：

$$
F(f(A), w) \leq F(f(B), w)
$$

否则就可能出现这样一种情况：当前路径代价较小的状态在扩展之后反而变得更大，从而使得算法按照代价排序的贪心顺序被打乱。换句话说，转移函数必须保证 “更优的前缀路径在扩展后仍然更优” ，这样 Dijkstra 才能安全地按照距离从小到大确定状态。

这两个条件可以用来判断某些特殊 “路径代价定义” 是否能够使用 Dijkstra。例如如果将路径代价定义为所有边权的按位或，即：

$$
f(P) = w_1 | w_2 | \dots | w_P
$$

则转移函数为：

$$
F(x, w) = x | w
$$

这种情况下单调性是成立的，因为按位或运算只会增加或保持原有的二进制位，因此必然满足 $x | w \geq x$ 。然而它不满足无后效性，因为即使 $f(A) \leq f(B)$ ，也不一定有 $f(A) | w \leq f(B) | w$ 成立。按位或运算会改变数值的二进制结构，使得扩展后的大小关系可能发生变化，从而破坏 Dijkstra 依赖的贪心顺序。因此，即使路径代价始终不下降，只要无法保证状态扩展后的顺序关系不被破坏，Dijkstra 仍然无法使用。

```cpp frame="code" title="main.cpp"
# include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN = 2e5 + 100;
const ll INF = 1e18;
struct Edge {
    int to, w;
};
vector<Edge> g[MAXN];
ll dist[MAXN];
bool vis[MAXN];
int n, m, s;

void dijkstra(int s){
    priority_queue<
        pair<ll,int>,
        vector<pair<ll,int>>,
        greater<pair<ll,int>>
    > pq;

    dist[s] = 0;
    pq.push({0, s});
    while (!pq.empty()){
        auto [d, u] = pq.top();
        pq.pop();

        if (vis[u]) continue;
        vis[u] = true;

        for (auto e : g[u]){
            int v = e.to;
            int w = e.w;

            if (dist[v] > dist[u] + w){
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
}
```

## Bellman 算法

Bellman–Ford 算法是一种用于求解 **单源最短路径问题** 的经典算法，与 Dijkstra 算法不同，它可以处理 **带负权边的图** 。设图中有 $n$ 个点、$m$ 条边，源点为 $s$ 。我们维护数组 $dist[v]$ 表示当前已知的从 $s$ 到 $v$ 的最短距离估计，初始时令 $dist[s] = 0$ ，其他点为无穷大。算法的核心思想是不断利用边进行松弛操作：如果存在一条边 $(u, v, w)$ 使得：

$$
dist[v] > dist[u] + w
$$

就更新这个点的距离：

$$
dist[v] = dist[u] + w
$$

这表示找到了更短的一条路径。

Bellman–Ford 的关键结论是：在一个没有负环的图中，从源点到任意节点的最短路径最多只包含 $n-1$ 条边。因此，只需要把所有边按任意顺序扫描并进行松弛操作 **$n-1$ 轮** ，就能够保证所有最短路径被正确计算出来。算法的正确性来自动态规划的思想：第 $k$ 轮松弛结束后，所有只包含不超过 $k$ 条边的最短路径都会被正确计算出来。经过 $n-1$ 轮之后，由于任何简单路径都不会超过 $n-1$ 条边，因此最短路一定已经确定。

Bellman–Ford 还有一个重要用途是 **检测负环** 。如果在完成 $n-1$ 轮松弛之后，再进行一轮松弛仍然能够更新某个节点的距离，那么说明存在一条可以无限降低路径长度的环，也就是负权环。因为如果最短路径不存在负环，那么在 $n-1$ 条边以内就已经达到最优，不可能再继续变小。

Bellman–Ford 的缺点是时间复杂度较高。由于每一轮都需要遍历所有 $m$ 条边，总复杂度为：

$$
O(nm)
$$

当图比较大时效率较低。为了减少不必要的松弛操作，人们提出了 **SPFA（Shortest Path Faster Algorithm）**，可以看作是对 Bellman–Ford 的一种队列优化。

SPFA 的基本思想是：并不是每一轮都需要扫描所有边。只有当某个节点的距离被更新之后，它的邻接边才有可能继续产生新的松弛。因此算法维护一个队列，初始时只把源点 $s$ 放入队列。当一个节点 $u$ 被取出时，遍历所有从 $u$ 出发的边 $(u, v, w)$ ，如果发现 $dist[v] > dist[u] + w$ 则更新 $dist[v]$ 。如果节点 $v$ 不在队列中，就把它加入队列。这样就只会处理那些 “可能继续产生更新” 的节点，从而避免大量无效扫描。

SPFA 在许多实际图上运行速度很快，平均复杂度通常接近 $O(m)$ ，但需要注意的是，它在理论上的最坏复杂度仍然是 $O(nm)$ ，甚至在某些特殊构造的图上会退化得很严重。因此在竞赛中，如果图没有负权边，一般仍然优先使用 Dijkstra，只有在存在负权边或需要检测负环时，才会使用 Bellman–Ford 或 SPFA。

SPFA 还可以用于 **负环检测** 。如果在算法过程中某个节点被加入队列的次数超过 $n$ 次，就说明从源点出发可以经过一条负环不断降低距离，从而判定图中存在负权环。这一点与 Bellman–Ford 的额外一轮检测本质上是相同的，只是实现方式不同。

```cpp frame="code" title="main.cpp"
# include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN = 2e5 + 100;
const ll INF = 1e18;
struct Edge {
    int to, w;
};
vector<Edge> g[MAXN];
ll dist[MAXN];
bool inq[MAXN];
int n, m, s;

void spfa(int s){
    queue<int> q;

    dist[s] = 0;
    q.push(s);
    inq[s] = true;
    while (!q.empty()){
        int u = q.front();
        q.pop();
        inq[u] = false;

        for (auto e : g[u]){
            int v = e.to;
            int w = e.w;

            if (dist[v] > dist[u] + w){
                dist[v] = dist[u] + w;

                if (!inq[v]){
                    q.push(v);
                    inq[v] = true;
                }
            }
        }
    }
}
```

## Floyd-DP 算法

在很多动态规划问题中，我们经常会遇到一种非常典型的结构：**从一个集合中逐渐选择元素，并在选择范围不断扩大的过程中维护最优解** 。例如经典的子序列问题，本质上就是从一个序列中选取一部分元素出来。对于序列中的每一个位置，我们都会面临一个决策：**选这个元素，或者不选这个元素** 。随着处理的位置不断向后推进，我们实际上是在逐渐扩大 “允许选择的元素集合” ，而动态规划的状态正是记录在当前集合限制下的最优答案。

从更抽象的角度来看，从序列中选取一部分元素，其实就是 **从一个集合中选择若干元素组成子集** 。因此很多 DP 问题都可以理解为：当我们逐步扩大可以使用的元素集合时，最优解如何变化。这个视角不仅适用于子序列问题，在图论问题中同样成立。**一条路径，本质上也是从图的节点集合中选取若干节点，并按顺序连接起来形成的一条结构** 。如果我们逐渐扩大 “允许使用的节点集合” ，那么在这个限制下的最短路径长度也会随之发生变化。

> 具体的思路讲解可以看一下灵神的这篇题解：[带你发明 Floyd 算法](https://leetcode.cn/problems/find-the-city-with-the-smallest-number-of-neighbors-at-a-threshold-distance/solutions/2525946/dai-ni-fa-ming-floyd-suan-fa-cong-ji-yi-m8s51/)

基于这个思路，我们可以把 Floyd 算法理解为一个非常自然的动态规划过程。我们定义状态：

$$
f(k, i, j)
$$

表示 **当前允许使用的节点中，编号最大的节点是 $k$ 时，从节点 $i$ 到节点 $j$ 的最短距离** 。这里的 $k$ 并不仅仅是一个普通的 “中间节点” ，而是一个 **集合的上界** 。当最大的可用节点是 $k$ 时，意味着路径上所有节点都必须来自集合：

$$
\{ 1, 2, \dots, k \}
$$

因此随着 $k$ 的增加，我们实际上是在不断扩大路径允许使用的节点范围。

当我们从 $k - 1$ 扩展到 $k$ 时，需要考虑路径是否会使用节点 $k$ 。如果一条最短路径不经过节点 $k$ ，那么它的所有节点仍然来自集合 $\{ 1, 2, \dots, k - 1 \}$ ，因此距离不会发生变化，仍然是：

$$
f(k-1, i, j)
$$

如果路径经过节点 $k$ ，那么这条路径一定可以被拆成两部分：从 $i$ 到 $k$ ，以及从 $k$ 到 $j$ 。而这两段路径中的节点都只能来自集合 $\{ 1, 2, \dots, k - 1 \}$ ，因为我们只允许 $k$ 作为新的最高编号节点。因此这两段路径的最短距离分别是：

$$
f(k-1, i, k), \quad f(k-1, k, j)
$$

于是就得到 Floyd 算法的状态转移关系：

$$
f(k, i, j) = \min \Big(f(k-1, i, j), f(k-1, i, k) + f(k-1, k, j) \Big)
$$

从动态规划的角度来看，这个转移结构其实与子序列问题非常相似。每一步本质上都是在决定 “是否使用当前元素” 。在子序列问题中，这个元素是序列中的某个位置；而在 Floyd 算法中，这个元素则是图中的一个节点。当我们枚举 $k$ 时，本质上就是在不断扩大允许使用的节点集合，并在这个集合限制下更新所有点对之间的最短路径。

```cpp frame="code" title="main.cpp"
# include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN = 505;
const ll INF = 4e18;
ll dist[MAXN][MAXN];
int n, m;

int main(){
    cin >> n >> m;
    for (int i = 1; i <= n; i++){
        for (int j = 1; j <= n; j++){
            if (i == j) dist[i][j] = 0;
            else dist[i][j] = INF;
        }
    }

    for (int i = 0; i < m; i++){
        int u, v; ll w;
        cin >> u >> v >> w;
        dist[u][v] = min(dist[u][v], w);
        dist[v][u] = min(dist[v][u], w);
    }

    for (int k = 1; k <= n; k++){
        for (int i = 1; i <= n; i++){
            for (int j = 1; j <= n; j++){
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
            }
        }
    }
}
```

# 简单图最短路问题

最短路问题是图论中最基础、也是最重要的一类问题之一。在一张带权图中，我们通常希望找到 **两点之间总代价最小的一条路径** ，而这个 “代价” 可以是距离、时间、花费或者其它抽象权值。在算法竞赛中，大量问题都可以抽象为最短路模型，因此掌握最短路算法几乎是图论学习的必经阶段。

从问题结构上看，最短路问题通常分为 **单源最短路** 和 **多源最短路** 两类。单源最短路要求求出从一个固定起点到图中所有点的最短距离，而多源最短路则需要求任意两点之间的最短距离。针对不同类型的问题，人们设计出了多种经典算法，例如 Dijkstra、Bellman–Ford（SPFA 优化）以及 Floyd 等。这些算法虽然形式不同，但本质上都是通过不断更新路径估计值，使最短距离逐渐逼近真实答案。

在算法竞赛中，很多题目的难点其实并不在于算法本身，而在于 **如何将问题正确地抽象成图模型** 。一旦成功建图，很多问题往往就可以直接转化为标准的最短路问题求解。因此，在学习具体算法之前，理解最短路问题的基本形式以及常见建图方式，是非常重要的一步。

接下来我们将从最基础的图最短路模型出发，逐步介绍几种经典最短路算法的核心思想、适用范围以及实现方式。通过这些算法的学习，可以帮助我们在面对复杂图论问题时，更自然地识别出其中隐藏的最短路结构。

## 奶牛的旅行问题

[提取链接](https://www.luogu.com.cn/problem/P1522)

### Problem Statement

农场上有 $N$ 块牧场，每块牧场有一个二维平面坐标。某些牧场之间已经存在直接路径，可以直接从一个牧场走到另一个牧场；如果两块牧场之间没有路径，则无法直接到达。

这些路径使得整个图可能被分成若干个 **互不连通的连通块** 。每个连通块内部的牧场都可以互相到达，但不同连通块之间无法到达。

现在农夫打算 **新建一条路径** ，连接两个原本不连通的牧场。新路径的长度等于两块牧场之间的 **欧几里得距离** 。

定义一个连通块的 **直径** 为：该连通块中任意两块牧场之间最短路径距离的最大值。

你的任务是选择一对牧场连接，使得 **连接之后整张图的最大连通块直径尽可能小** 。输出这个最小可能的直径。

结果保留 **6 位小数** 。

### Constraints

- $1 \leq N \leq 150$
- 坐标范围：$|x_i|, |y_i| \leq 10^4$

### Input

输入包含：

* 第一行一个整数 $N$ ，表示牧场数量。
* 接下来 $N$ 行，每行两个整数 $x_i, y_i$ ，表示第 $i$ 个牧场的坐标。
* 接下来 $N$ 行，每行包含一个长度为 $N$ 的 `0/1` 字符串：

  * `1` 表示两个牧场之间存在路径
  * `0` 表示没有路径

输入格式示意：

> $N$
> 
> $x_1 \quad y_1$
> 
> $x_2 \quad y_2$
> 
> $\ldots$
> 
> $x_N \quad y_N$

### Output

输出一个浮点数，表示连接一条新路径之后的最小可能直径，结果保留 6 位小数。

### Sample Input 1

```txt showLineNumbers=false
4
0 0
0 1
10 10
10 11
0110
1010
0101
0010
```

### Sample Output 1

```txt showLineNumbers=false
14.142136
```

## 题目要点解析

树结构中有一个非常重要的性质：如果将两棵树通过一条边连接起来，那么新树的直径端点一定来自于原来两棵树直径端点的集合。换句话说，假设两棵树的直径端点分别为 $(a,b)$ 与 $(c,d)$ ，那么新树的直径端点一定是这四个点中的任意两个。因此，新树的直径只可能有两种情况：要么仍然是原来两棵树直径中较大的那个，要么是经过新连接边的一条路径，而这条路径的两个端点一定来自原来直径端点集合中的两个点。

在本题中，原图并不是一棵树，而是由若干个 **互不连通的连通块** 组成的图。每一个连通块内部都可以看作一个独立的结构，其内部已经存在路径，因此每个连通块内部也同样存在一个 “直径” ，即该连通块中任意两点最短路的最大值。当我们新增一条边连接两个不同连通块时，新图的直径同样只可能来自两种来源：一种是原来各个连通块中的最大直径；另一种是 **跨越新连接边形成的新路径** 。

对于跨连接边形成的路径，其结构可以表示为：

$$
dist(u,x) + w(u,v) + dist(v,y)
$$

其中 $u,v$ 是新连接的两个点，$x$ 是 $u$ 所在连通块中的某个点，$y$ 是 $v$ 所在连通块中的某个点。因此这条路径的最大值取决于 $u$ 与所在连通块中最远点的距离，以及 $v$ 与其连通块最远点的距离。为了使新图的直径尽可能小，我们希望选择的连接点能够让这些最远距离尽量小。

这就引出了 **连通块中心点** 的概念。对于一个连通块中的某个点 $p$ ，定义：

$$
ecc(p) = \max_{v} dist(p,v)
$$

也就是从该点到连通块中最远节点的最短路距离。如果我们在所有点中选择使 $ecc(p)$ 最小的点，那么这个点就可以看作该连通块的 **中心点** 。直观上理解，中心点就是距离整个连通块最 “居中” 的位置，从这里向外扩展时，最远距离最小。因此，当我们需要在两个连通块之间添加一条边时，连接两个连通块的中心点能够使跨边路径的长度最小。

为了求出这些距离信息，我们首先需要得到图中 **任意两点之间的最短距离** 。由于题目规模较小，可以直接使用 Floyd 算法进行全源最短路计算。Floyd 算法能够在 $O(n^3)$ 的时间内求出所有点对之间的最短路径，这样我们就可以方便地获得任意两点之间的距离。

当所有最短路计算完成后，我们就可以对每个点计算其 $ecc$ 值，也就是它到所在连通块中最远点的距离。同时还可以求出每个连通块当前的直径。接下来枚举两个原本不连通的点 $u,v$ ，假设在它们之间新建一条边，其长度为两点之间的欧几里得距离，那么通过这条边形成的新路径长度为：

$$
ecc(u) + dist(u,v) + ecc(v)
$$

此时新图的直径就是原来各连通块直径的最大值与这条跨边路径长度之间的较大者。我们枚举所有可能的连接方式，并取其中直径最小的方案作为答案即可。

整体算法流程可以概括为：先使用 Floyd 求出所有点对最短路；然后计算每个点的最远距离以及各连通块的直径；最后枚举不同连通块之间的连边方案，计算新图的直径并取最小值。由于 $n \leq 150$ ，Floyd 的复杂度是可以接受的，因此这种直接枚举的方法能够顺利通过本题。

## 题目要点解析

对于 **恰好走 k 步** 的路径问题，一个非常常见的建模技巧是 **分层图** 。具体做法是将原图复制 $k$ 层，第 $i$ 层表示已经走了 $i$ 步的状态。如果原图中存在一条边 $u \to v$ ，那么就在第 $i$ 层向第 $i+1$ 层连一条边 $(u,i) \to (v,i+1)$ ，边权与原图相同。这样一来，从起点状态 $(S,0)$ 出发，到达终点状态 $(E,k)$ 的最短路径，就对应着 **恰好走 k 条边** 的最短路问题。建图完成后，只需要在这张扩展图上跑一次最短路即可。

然而在本题中，这种方法会遇到一个明显的问题：题目给出的 $N$ 非常大。如果按照分层图的方式建图，就需要构造 $N$ 层图结构，图的规模将会膨胀到原来的 $N$ 倍。当 $N$ 达到 $10^6$ 量级时，无论是空间还是时间都无法接受，因此这种直接扩图的方法在这里并不可行。

观察最短路的转移方式，可以得到一个更本质的递推关系。设 $f_k(i,j)$ 表示从节点 $i$ 出发，**恰好经过 k 条边** 到达节点 $j$ 的最短距离。若最后一步是从某个节点 $t$ 走到 $j$ ，那么有：

$$
f_k(i,j) = \min_t \left( f_{k-1}(i,t) + w(t,j) \right)
$$

这个转移形式与矩阵乘法非常相似。普通矩阵乘法是：

$$
C_{ij} = \sum_k A_{ik} \times B_{kj}
$$

而这里的运算则变成：

$$
C_{ij} = \min_k (A_{ik} + B_{kj})
$$

这种运算被称为 **min-plus 矩阵乘法** 。如果把 $A_{ij}$ 定义为从 $i$ 到 $j$ **恰好走一条边** 的最短距离，那么通过一次 min-plus 乘法就可以得到 **恰好走两条边** 的最短距离；继续进行乘法，就可以得到更多步数的结果。

因此，从 $i$ 到 $j$ 恰好走 $N$ 条边的最短路，本质上等价于对这个权值矩阵进行 **N 次 min-plus 乘法** 。直接做 $N$ 次乘法显然仍然不可行，但由于矩阵乘法具有结合律，我们可以使用 **矩阵快速幂** 的思想，将复杂度从 $O(N)$ 次乘法降低到 $O(\log N)$ 次乘法。

最终的算法流程就是：首先构造一个矩阵 $A$ ，其中 $A_{ij}$ 表示从 $i$ 到 $j$ 经过一条边的最短距离；然后通过 **min-plus 矩阵快速幂** 计算 $A^N$ 。矩阵 $A^N$ 中的第 $S,E$ 个元素，就表示从 $S$ 出发恰好经过 $N$ 条边到达 $E$ 的最短路径长度。由于图中实际出现的节点数量不超过一百个左右，因此矩阵规模较小，整体复杂度约为 $O(n^3 \log N)$ ，可以顺利通过本题的数据范围。

## 题目要点解析

这道题的本质是一个 **带约束的最短路计数问题** 。题目要求我们不仅要统计从起点 $S$ 到终点 $F$ 的最短路径条数，还要统计比最短路径长度恰好大 $1$ 的路径条数。由于图中的边权均为正整数，我们可以将其转化为在扩展状态空间下的最短路搜索模型。

首先考虑基础的 **最短路计数** 。在标准的 Dijkstra 算法中，我们通过松弛操作（Relaxation）更新起点到每个节点 $i$ 的最短距离 `dist[i]` 。为了统计条数，我们可以引入一个计数数组 `cnt[i]` 。当发现一条更短的路径时，我们不仅更新 `dist[i]` ，还要将 `cnt[i]` 覆盖为前驱节点的计数；当发现一条路径长度等于当前的 `dist[i]` 时，则将前驱节点的计数累加到 `cnt[i]` 中。这种做法利用了最短路路径的 **最优子结构性质** 。

对于本题要求的最短路与次短路，我们需要进一步扩展状态。由于我们要找的是特定长度的路径，可以为每个节点维护两个独立的状态：`dist[i][0]` 表示到达节点 $i$ 的 **最短距离** ，`dist[i][1]` 表示到达节点 $i$ 的 **次短距离** 。相应地，我们也需要两个计数数组 `cnt[i][0]` 和 `cnt[i][1]` 。在 Dijkstra 的堆优化过程中，每次从优先队列取出当前距离最小的状态 $(u, d, type)$ ，并尝试更新其邻接节点 $v$ 。

在更新节点 $v$ 时，设当前路径长度为 $W = d + weight(u, v)$ ，会出现以下四种情况：

1. **$W < dist[v][0]$**：找到了更短的路径。此时原来的最短路降级为次短路，即 `dist[v][1] = dist[v][0]` ，`cnt[v][1] = cnt[v][0]` ；同时更新最短路 `dist[v][0] = W`，`cnt[v][0] = cnt[u][type]` 。
2. **$W == dist[v][0]$**：找到了另一条长度相等的最短路。直接累加计数：`cnt[v][0] += cnt[u][type]` 。
3. **$W < dist[v][1]$**：长度介于最短路和次短路之间。此时更新次短路：`dist[v][1] = W`，`cnt[v][1] = cnt[u][type]` 。
4. **$W == dist[v][1]$**：找到了另一条长度相等的次短路。直接累加计数：`cnt[v][1] += cnt[u][type]` 。

最后，我们需要根据计算结果判断哪些路径符合最短路 $+1$ 的条件。在算法结束时，`cnt[F][0]` 始终是我们要找的最短路径条数。如果计算出的次短路长度 `dist[F][1]` 恰好满足 `dist[F][0] + 1` ，那么最终答案就是 `cnt[F][0] + cnt[F][1]` ；否则，次短路不符合要求，答案仅为 `cnt[F][0]` 。这种状态拆分的方法保证了我们在搜索过程中能够完整保留所需的路径信息，且依然满足 Dijkstra 算法的贪心选择性质。

# 分层图最短路问题

分层图最短路问题，本质上是一种 “通过扩充状态来刻画过程” 的建模方法。很多时候，原图中的一个节点并不能完整表达我们当前所处的状态，例如还剩多少资源、是否使用过某种特殊操作、当前处于第几阶段等。如果直接在原图上跑最短路，就会丢失这些关键信息。于是我们引入 **分层的思想**：把原本的一个节点，按照不同状态拆成多个节点，每个节点代表 “原节点 + 某种附加信息” 。这样一来，路径上的所有决策信息都被显式地记录下来，问题就转化成一个更大的图上的最短路问题。

从思想上看，**分层图和动态规划非常相似** 。动态规划是通过增加状态维度，使得每一个状态都能完整表示一个子问题；分层图则是通过增加图的层数，使得每一个节点都能完整表示一个 “位置 + 状态” 。尤其是当我们接触过状压 DP 时，会发现它和分层图更为相似：都是通过人为地增加维度，让状态空间覆盖所有可能的解空间。一旦状态设计得足够完整，问题就退化成 “在这个扩展后的状态空间里做一次普通的最短路” ，本质上是一种系统化的枚举。

当然，**状态扩展并不是越多越好** 。理论上，如果我们把所有可能的信息都加入状态，那么一定可以覆盖所有合法方案，但代价往往是状态数指数级增长，时间和空间复杂度都难以承受。因此，分层图建模最关键、也最困难的地方就在于：如何找到一个恰到好处的状态设计。状态要足够丰富，能够保证正确性；同时又要足够精简，使得图的规模仍然可控。这个 “平衡点” 决定了算法是否可行。

在实际建模时，我们通常会围绕 “路径上的限制条件” 来思考。比如是否允许使用一次特殊技能、是否有限次数的操作、路径长度是否对某些性质有影响等。每增加一个限制条件，往往就对应一个新的维度或新的层。例如，“最多使用一次免费通行” 可以扩成两层图（未使用和已使用）；“恰好走 K 步完成一次操作” 可以扩成 K 层循环结构；“当前模某个数的余数” 也可以扩成若干层。这些层之间通过特定规则连边，从而精确模拟题目的过程。

总结来说，分层图是一种通过 “增加状态维度” 来换取 “问题结构清晰化” 的方法。它的思想和 DP 一脉相承，本质上是 **用空间换时间、用结构化的暴力换取确定性解法** 。掌握分层图的关键，不在于记住某种固定模板，而在于学会分析问题的本质约束，并设计出既完整又高效的状态空间。当状态设计得恰到好处时，原本复杂的路径决策问题，就会自然地转化为一个清晰可解的最短路模型。

## 题目要点解析

这道题第一眼看上去和普通最短路非常相似，只不过把 “路径权值求和” 换成了 “路径权值按位异或” 。如果是 **加法** ，那么我们可以 **直接使用 Dijkstra 算法** ，因为在边权非负的情况下，路径长度是单调递增的，也就是说当我们确定某个点当前的最短距离时，它之后不可能再被更优的路径更新，这种单调性保证了贪心策略的正确性。但在本题中路径代价是通过 **异或运算** 得到的，而异或运算本质上是 **非单调的** ，例如：

$$
8 \oplus 8 = 0
$$

这说明路径变长之后，总代价反而可能减小，因此 **“当前最优就一定最终最优”** 这一贪心前提被破坏，Dijkstra 算法无法直接套用。既然异或不满足单调性，我们就必须换一个角度思考问题。观察数据范围可以发现，边权满足：

$$
0 \leq W_i < 2^{10}
$$

由于异或运算不会产生更高位的进位，因此任意路径的异或结果也一定满足：

$$
0 \leq \text{XOR} < 2^{10}
$$

这意味着所有可能的路径异或结果最多只有 $1024$ 种情况。这个结论非常关键，它说明路径的 **“历史信息” 其实是有限的** ，我们完全可以把这种历史信息作为状态的一部分进行建模。具体来说，我们不再只记录 “当前在哪个节点” ，而是把状态扩充为 “当前节点 + 当前前缀异或值” 。也就是说，我们的状态定义为：

$$
(v, sum)
$$

其中 $v$ 表示当前顶点，$sum$ 表示当前的前缀异或值。若我们从节点 $1$ 出发时，初始状态是 $(1, 0)$ ，因为还没有走任何边，前缀异或为 $0$ 。假设原图中存在一条边 $u \rightarrow v,\ 权值为\ w$ ，如果我们当前处在状态 $(u, x)$ ，那么经过这条边之后，就会转移到：

$$
(v, x \oplus w)
$$

这样我们就把 “路径历史” 显式地编码进了状态之中，原图中的每个节点会被复制 $1024$ 次，每一层代表不同的前缀异或值。整个问题就转化为在这个扩充后的图中，从状态 $(1, 0)$ 出发，寻找所有能够到达的 $(N, x)$ ，然后在这些 $x$ 中取最小值。如果不存在任何可以到达的状态 $(N, x)$ ，则说明不存在从 $1$ 到 $N$ 的 walk，答案为 $-1$ 。

由于状态总数为 $N \times 2^{10}$ ，而 $N \le 1000$ ，因此最多约为 $10^6$ 级别，完全可以接受。每条原图中的边在扩充图中最多会产生 $1024$ 条状态转移，所以整体时间复杂度大约为 $O(M \times 2^{10})$ 。

## 题目要点解析

Dijkstra 之所以能够成立，本质是因为它依赖于 DP 的无后效性。最短路问题通常默认有：

$$
\mathrm{dist}[C] = \mathrm{dist}[B] + \mathrm{cost}(B \to C)
$$

其中转移代价 $\mathrm{cost}(B \to C)$ 仅依赖于当前状态 $B$ ，而与到达 $B$ 的具体路径无关。因此一旦某个顶点 $B$ 的最优距离被确定，则从该顶点出发的所有后续扩展，其代价结构应当是固定且独立于历史路径的。在这一条件下，贪心地锁定当前最小距离顶点才具有理论保证。

显然本题并不满足上述条件。题目中的总代价并非简单的边权累加，而是与路径中各顶点所处的位置相关。具体而言，路径长度的不同会导致同一顶点在不同路径中承担不同的权重贡献。因此，即使两条路径到达同一个顶点，其后续扩展的代价模型也可能不同。这意味着，在原图中仅以 $\mathrm{dist}[v]$ 作为状态是不充分的，因为该状态未记录 “已行进步数” 这一影响后续代价的关键信息。由此可见，原问题在顶点层面并不满足无后效性，直接在原图上应用 Dijkstra 算法缺乏依据。

为恢复无后效性，可以从[对象转化贡献法](https://xingguang641.com/posts/acm/acm-note/optimization/#对象交换贡献法)的角度对问题进行重新建模。设一条从起点到终点的路径长度为 $L$ 。若路径上的某个顶点距离终点还剩 $k$ 步，则其对总代价的贡献为 $k W$ ，其中 $W$ 为该顶点的权值。于是，整条路径的总代价可表述为所有顶点权值在其 “剩余步数” 意义下的加权求和。问题因此转化为在所有合法路径中，寻找一条使上述加权和最小的路径。为刻画 “剩余步数” 这一变量，需要对原图进行状态扩展。

构造新的状态空间：

$$
(v, k)
$$

其中 $v$ 表示当前顶点，$k$ 表示到达终点尚需的步数。若存在原图边 $u \to v$ ，则在扩展图中引入转移：

$$
(u, k) \to (v, k-1)
$$

并赋予其权值：

$$
k W_u
$$

在该建模下，每条边的权值成为确定常数，不再依赖更早的路径历史，状态描述亦趋于完整。由于第二维 $k$ 在转移过程中单调递减，扩展图构成一张有向无环图，从而可以按拓扑顺序进行求解，其时间复杂度为 $O(NM)$ 。

## 题目要点解析

这道题的核心在于理解 **一次 “操作” 的本质** 。题目允许我们从当前顶点出发，移动到距离恰好为 $K$ 的顶点，并且可以重复若干次。若直接从定义出发，很自然会想到构造一个 **K 步图**：对于原树中的每个顶点 $v$ ，将所有与 $v$ 距离为 $K$ 的顶点连边，然后在这张新图上做最短路，答案即为最少跳跃次数。从理论上讲，这种思路完全正确，甚至可以用 **邻接矩阵快速幂** 来刻画 “恰好走 $K$ 步” 的可达关系。然而，矩阵乘法的复杂度过高，在 $N$ 达到 $2\times 10^5$ 量级时显然无法承受，因此我们不能显式构造这张 $K$ 步图。

关键转折在于 **对 “跳跃” 进行拆解** 。一次跳跃本质上是沿树边连续走 $K$ 步。因此，与其一次性考虑 “走到距离为 $K$ 的点” ，不如把问题转化为：在树上按边逐步行走，同时记录当前已经走了多少步。当累计步数达到 $K$ 时，视为完成一次操作，并重新开始计数。这样，我们就不再需要构造 $K$ 步图，而是在原图的基础上引入阶段这一维度。

为此，我们构造分层图状态：

$$
(v, k)
$$

其中 $v$ 表示当前所在顶点，$k$ 表示当前总步数对 $K$ 取模的结果。换言之，$k$ 表示当前这次跳跃已经走了多少步（范围为 $0 \leq k < K$ ）。初始状态为 $$(1, 0)$ ，表示从顶点 $1$ 出发，尚未开始新的跳跃。

从状态 $(v, k)$ 出发，可以沿原树中的任意一条边走到相邻顶点 $u$ ，并转移到状态 $(u, (k+1) \bmod K)$ 。当 $k+1 \equiv 0 \pmod K$ 时，说明恰好完成了一次 **长度为 K 的连续移动** ，此时我们记录到达该顶点所需的操作次数为当前总步数除以 $K$ 。整个过程可以用 BFS 实现，因为每走一条边的代价为 $1$ ，BFS 能保证首次到达某个 “完成跳跃” 的状态时，其操作次数最小。

如果仅仅构造这样的分层图，仍可能出现复杂度过高的问题。因为在树中，每个顶点可能有较高的度数，而同一个 $(v, k)$ 状态可能从不同方向多次到达，从而重复扩展邻边。若不加限制，最坏情况下会退化为 $O(N^2K)$。

优化的关键在于利用 **树的结构** 。注意到在一次尚未完成的跳跃过程中（即 $k \neq 0$ 时），我们不允许立即沿刚才走过的边原路返回，否则相当于在一条简单路径中产生回溯。由于 **树是无环图** ，若禁止中途回头，那么在一次跳跃内部，路径必然是一条 **简单路径** 。这样一来，对于固定的 $(v, k)$ ，从结构上讲，最多只会有两种 “不同方向” 的到达方式；第三次到达时所能产生的后续转移，必然已经在前两次扩展中覆盖。因此，我们可以对每个 $(v, k)$ 只允许 **处理至多两次** ，从而避免重复扩展。

在实现上，可以额外记录每个 $(v, k)$ 被访问的次数，当次数达到 $2$ 时停止继续扩展。由于树中边数为 $N-1$ ，所有状态数为 $N \times K$ ，每个状态至多扩展常数次，整体时间复杂度便可控制在 $O(NK)$ 。在题目给定的 $K \leq 20$ 条件下，这是完全可行的。

# 操作次数最短路

在算法竞赛与理论计算机科学中，**“最少操作次数” 问题往往可以统一抽象为最短路问题** 。其基本思想是：将 “状态” 视为图中的顶点，将 “操作” 视为从一个状态到另一个状态的有向边，若每次操作代价为 $1$ ，则问题即转化为从初始状态到目标状态的最短路径问题；若不同操作具有不同代价，则对应为带权最短路问题。这种抽象具有高度的一般性，本质上是将离散的动态过程形式化为图上的路径搜索，从而可以直接应用 **BFS 、Dijkstra 或更一般的最短路算法** 进行求解。

然而，这种建模方式的核心挑战并不在算法本身，而在于 **状态空间的规模控制** 。理论上，只要状态与转移规则可以枚举，任何问题都可以被构造成一张图；但在实践中，状态数往往呈指数级增长。例如，当状态由多个布尔变量、集合选择或排列结构构成时，可能产生 $2^n$ 、$3^n$ 或 $n!$ 级别的状态空间，从而使显式构图或常规最短路算法在时间和空间上均不可行。因此，尽管 “最少操作次数 = 最短路” 在逻辑上始终成立，但在工程实现层面，其可行性取决于状态规模是否可控。

从方法论角度看，此类问题的关键在于两个方面。第一，应当对状态空间进行严格估计，结合题目数据范围判断是否能够承受。例如，当状态数量上界为 $O(N)$ 、$O(NK)$ 、$O(2^K)$ 且 $K$ 较小时，通常可以考虑直接构造状态图并进行 BFS。第二，需要分析是否存在 **等价状态、冗余转移或可剪枝结构** ，从而通过状态压缩、哈希判重或利用问题的单调性与对称性来减少搜索规模。许多问题表面上状态复杂，但通过适当抽象后，真实有效状态远少于理论上界。

值得强调的是，这种基于状态图的最短路建模在竞赛题中往往并非显性提示，而是隐藏在 “最少次数” 、“最少步数” 、“最小操作数” 等表述之下。因此，在审题阶段应当形成一种结构化反应：一旦出现 “最少” 与 “操作” 这类关键词，应优先思考是否可以建立 **状态转移图模型** 。若经估算状态空间可接受，则应果断采用图论方法，而不必因其看似 “暴力” 而犹豫。事实上，在部分题目中，这种直接建模反而是出题人预期的标准解法。

# 最短路树相关问题

在许多最短路相关问题中，我们往往不仅需要求出从源点到各个节点的最短距离，还需要进一步分析 **哪些边可能出现在最短路径上** ，或者 **在所有最短路径上进行额外计算** 。这时，一个非常重要的技巧就是构造 **最短路图** 或 **最短路树** 。它们本质上都是在最短路算法结束之后，根据已经求出的距离信息，对原图进行一次结构提取。

这一结构的来源可以直接从最短路算法中的 **松弛操作** 理解。以 Dijkstra 为例，在算法执行过程中，我们不断进行如下松弛判断：

```cpp showLineNumbers
if (dis[v] > dis[u] + w) {
    dis[v] = dis[u] + w;
}
```

当算法结束时，数组 `dis[]` 中记录的就是从源点 $s$ 到每个节点的最短距离。如果某条边 $(u,v)$ 的权值为 $w$ ，并且满足：

$$
dis[v] = dis[u] + w
$$

那么说明这条边恰好满足最短路的转移关系，也就是说 **存在一条最短路径是通过这条边从 u 到达 v** 。换句话说，这条边有可能出现在某一条最短路径之中。如果我们把 **所有满足上述条件的边全部保留下来** ，就得到了一张新的图。这张图只包含那些能够保持最短距离转移关系的边，因此其中任意一条从源点出发的路径，都会保持最短距离的正确累加关系。这张图就称为 **最短路图（Shortest Path Graph）**。

在通常的最短路问题中，如果不存在零环或负环，那么沿着这些边行走时，节点的最短距离会不断增加，也就是：

$$
dis[v] > dis[u]
$$

因此不可能回到之前的节点，从而不会形成环。也正因如此，最短路图通常是一张 **有向无环图（DAG）**。这一性质非常重要，因为一旦得到 DAG，我们就可以在其上进行拓扑排序或动态规划，从而解决许多更复杂的问题，例如统计最短路径数量、计算最短路径上的最大收益等。

在最短路图的基础上，如果我们进一步 **为每个节点只选择一条满足最短路转移关系的入边** ，那么最终得到的结构就会是一棵树。这棵树以源点为根，树上从源点到任意节点的路径长度都恰好等于最短距离，因此它被称为 **最短路树（Shortest Path Tree）**。

如果图中从源点到每个节点的最短路径是唯一的，那么最短路图本身就已经是一棵树，此时最短路树也是唯一的。但在很多情况下，最短路径可能不止一条，此时最短路图会包含多条可能的转移边，而最短路树则只是从这些边中 **选取一组前驱关系形成的一棵生成树** 。因此可以认为，**最短路树是最短路图的一棵生成树** 。
