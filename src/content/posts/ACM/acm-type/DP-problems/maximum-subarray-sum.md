# 单区间累加和问题

在动态规划的建模范式中，**连续子数组** 类问题展现了一种独特的结构约束。由于子数组必须保持物理位置的 **绝对连续性** ，问题的核心价值并不在于对既有模型的简单套用，而在于如何通过状态设计将弥散的区间搜索空间锚定在具体的递推节点上。与可以跳跃选择的子序列不同，子数组问题的关键在于：当我们处理到某个位置时，必须强制性地考察 “以当前位置为结尾” 的最优局部解，从而确保递推链条的不中断。

动态规划的核心在于：**通过定义状态，刻画 “以当前位置为结尾” 的最优解，并利用前一状态的信息进行转移** 。在子数组最大累加和问题中，我们通常设 $dp[i]$ 表示 “以第 $i$ 个位置结尾的最大子数组和” ，从而得到清晰的递推关系。每一步只需在 “延续之前的最优结果” 与 “从当前位置重新开始” 之间作出选择。这种思想强调局部最优如何通过状态传递构成全局最优。

因此，连续子数组建模的本质是利用 **局部结尾的强制性** 来换取 **全局状态的确定性** 。有效的建模技巧源于对这种连续性约束的深刻理解，通过将状态锚定在当前步的结尾，我们能够利用前一状态的信息进行极简的转移，而无需回溯复杂的历史决策。这种思想强调局部最优如何通过严谨的递推结构构成全局最优。理解了这一层逻辑，便能在面对更复杂的连续性约束问题时，构造出逻辑严密且复杂度可控的动态规划模型。

## 子数组最大总和

[题目链接](https://leetcode.cn/problems/maximum-subarray)

### Problem Statement

给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组是数组中的一个连续部分。

### Constraints

- $1 \leq nums.length \leq 10^5$
- $-10^4 \leq nums[i] \leq 10^4$

### Input

输入包含两行：

- 第一行包含一个整数 $n$ ，表示数组长度。
- 第二行包含 $n$ 个整数，表示数组中的各个元素。

### Output

输出一个整数表示答案。

### Sample Input 1

```txt showLineNumbers=false
9
-2 1 -3 4 -1 2 1 -5 4
```

### Sample Output 1

```txt showLineNumbers=false
6
```

## 题目要点解析

连续子数组问题的建模核心在于利用 “以当前位置结尾” 的强制性约束，将弥散的搜索空间锚定在递推节点上。由于子数组必须保持物理位置的绝对连续，我们定义 $dp[i]$ 为以第 $i$ 个元素结尾的最大子数组和，从而将全局的区间搜索转化为局部的二选一抉择：是承接前一位置的累加增益，还是以当前元素为起点重新开启序列。

其核心递推关系简洁地表达为：

$$
dp[i] = \max(nums[i], dp[i-1] + nums[i])
$$

这种建模技巧的本质是用局部结尾的确定性来换取状态转移的极简性。通过一次线性扫描，我们在每一个递推步中捕获局部最优，并在遍历过程中维护全局最大值，从而在 $O(n)$ 的时间复杂度内完成对连续性约束问题的完美求解。

```cpp frame="code" title="main.cpp"
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN = 1e5 + 100;
int a[MAXN]; ll dp[MAXN];

int main() {
    int n; cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    dp[0] = a[0]; ll ans = a[0];
    for (int i = 1; i < n; i++) {
        dp[i] = max((ll)a[i], dp[i - 1] + a[i]);
        ans = max(ans, dp[i]);
    }

    cout << ans << endl;
}
```

## 环数组最大总和

[题目链接](https://leetcode.cn/problems/maximum-sum-circular-subarray/)

### Problem Statement

给定一个长度为 `n` 的 **环形整数数组** `nums` ，请你找出该数组中具有最大和的 **非空连续子数组** ，并返回其最大和。

**环形数组** 意味着数组的末端将会与开头相连呈环状。形式上，`nums[i]` 的下一个元素是 `nums[(i + 1) % n]` ，而 `nums[i]` 的前一个元素是 `nums[(i - 1 + n) % n]` 。

### Constraints

- $n = nums.length$
- $1 \leq n \leq 3 \times 10^4$
- $-3 \times 10^4 \leq nums[i] \leq 3 \times 10^4$

### Input

输入包含两行：

- 第一行包含一个整数 $n$ ，表示数组长度。
- 第二行包含 $n$ 个整数，表示环形数组中的各个元素。

> $n$
> 
> $nums_1, nums_2, \ldots, nums_n$

### Output

输出一个整数表示答案。

### Sample Input 1

```txt showLineNumbers=false
3
1 -2 3
```

### Sample Output 1

```txt showLineNumbers=false
3
```

### Sample Input 2

```txt showLineNumbers=false
3
5 -3 5
```

### Sample Output 2

```txt showLineNumbers=false
10
```

## 题目要点解析

在处理 **环形连续子数组** 类问题时，动态规划的建模范式由单一的增益维护演变为一种基于 **分类讨论** 的系统化求解。环形结构的特殊性在于其解空间存在两种截然不同的物理形态，这要求我们必须跳出单纯的线性思维，通过对问题的结构化拆解来实现全空间的覆盖。

针对环形数组，常见的处理策略通常分为两类：一种是 **倍增数组法** ，即通过构造 $2n$ 长度的数组将环形展平，虽然逻辑直观，但在处理子数组长度限制时往往会导致复杂度上升；而另一种更为高效的策略则是 **分类讨论法** ，其核心在于通过考察子数组是否 “跨越边界” ，将一个复杂的拓扑问题转化为两个并行的 **对偶问题** 。

首先考虑 **不跨越边界** 的情况：此时子数组完全包含在原数组 $a[0 \dots n-1]$ 内部，问题等价于经典的线性子数组最大累加和。我们通过维护以当前位置结尾的最大增益 $dp_{max}[i]$ ，在局部最优的递推中捕捉全局最大值。

其次考虑 **跨越边界** 的情况：子数组由原数组的后缀与前缀拼接而成。在逻辑建模上，跨越边界的最大子数组，其补集必然是一个位于数组中间且连续的 **最小子数组**。因此，求解 “跨越型” 最大和的任务，便转化为求解线性数组最小累加和这一 **对偶问题** 。

这种分类讨论的本质是利用状态的对称性，将核心递推关系定义为最大与最小状态的 **对偶演进**：

$$
dp_{max}[i] = \max(a[i], dp_{max}[i-1] + a[i])
$$

$$
dp_{min}[i] = \min(a[i], dp_{min}[i-1] + a[i])
$$

通过强制锚定局部结尾的极值，我们得以在 $O(n)$ 的线性扫描中同时捕获两种形态的候选解。最终的全局最优解在 $\max(dp_{max})$ 与 $TotalSum - \min(dp_{min})$ 之间产生。这种 **对偶逻辑** 不仅巧妙地规避了显式的环形遍历，更体现了动态规划在处理复杂约束时化繁为简的建模魅力。需要注意的是，当数组全为负值时，需避开补集为空集的逻辑陷阱，直接取 $dp_{max}$ 的全局最大值作为结果。

```cpp frame="code" title="main.cpp"
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN = 1e5 + 100;
int a[MAXN];
ll dp_max[MAXN], dp_min[MAXN];

int main() {
    int n; cin >> n;
    ll total_sum = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        total_sum += a[i];
    }

    dp_max[0] = dp_min[0] = a[0];
    ll max_ans = a[0];
    ll min_ans = a[0];
    for (int i = 1; i < n; i++) {
        dp_max[i] = max((ll)a[i], dp_max[i - 1] + a[i]);
        max_ans = max(max_ans, dp_max[i]);

        dp_min[i] = min((ll)a[i], dp_min[i - 1] + a[i]);
        min_ans = min(min_ans, dp_min[i]);
    }

    if (max_ans < 0) {
        cout << max_ans << endl;
    } else {
        cout << max(max_ans, total_sum - min_ans) << endl;
    }
}
```

## 子数组最大乘积

## 题目要点解析

这道题与 “最大子数组累加和” 的逻辑如出一辙，核心思路并没有本质区别。我们依然是在维护一个以当前位置结尾的最优状态，只不过运算规则从加法变成了乘积。但在处理乘法时，负数带来的影响是绝对不能忽视的。在加法运算中，负数顶多是让和变小，但在乘法里，两个负数相乘反而会得正，这种 “负负得正” 的特性让局面变得复杂了许多。

为了应对负数可能引发的性质翻转，我们不能像处理加法那样只盯着最大值。我们需要同步维护两个状态：一个是以当前位置结尾的最大乘积 $dp_{max}[i]$ ，另一个则是专门用来防备翻盘的最小乘积 $dp_{min}[i]$ 。每当我们遇到一个新的数字 $nums[i]$ ，实际上是在三条演进路径中寻找最强的那个：要么是顺着之前的最大值继续乘下去，要么是利用当前的负数去撞之前的最小值实现负负得正，再或者就是嫌弃前面的积攒太烂，直接以当前数字为起点重新开始。

其核心的递推逻辑可以非常直观地表达为：

$$
dp_{max}[i] = \max(nums[i], dp_{max}[i-1] \cdot nums[i], dp_{min}[i-1] \cdot nums[i])
$$

$$
dp_{min}[i] = \min(nums[i], dp_{max}[i-1] \cdot nums[i], dp_{min}[i-1] \cdot nums[i])
$$

通过这种同步维护最大与最小值的策略，算法得以在一次 $O(n)$ 的线性扫描中，把正数增长、负数翻转以及遇到零点截断的情况全空间覆盖。这种建模思想精简了繁琐的分类讨论，纯粹利用两个对称的状态体系，稳健地将局部最优传递给全局最优。

```cpp frame="code" title="main.cpp"
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN = 2e4 + 100;
int a[MAXN];
ll dp_max[MAXN], dp_min[MAXN];

int main() {
    int n; cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    dp_max[0] = dp_min[0] = a[0];
    ll ans = a[0];
    for (int i = 1; i < n; i++) {
        ll cur = a[i];
        ll nxt_max = max({(ll)cur, dp_max[i - 1] * cur, dp_min[i - 1] * cur});
        ll nxt_min = min({(ll)cur, dp_max[i - 1] * cur, dp_min[i - 1] * cur});
        
        dp_max[i] = nxt_max;
        dp_min[i] = nxt_min;

        ans = max(ans, dp_max[i]);
    }

    cout << ans << endl;
}
```

# 子序列累加和问题

与强调连续性的子数组问题不同，**子序列** 类问题在元素选择上具有更高的自由度，其核心特征在于元素可以不连续，但必须保持原有的相对顺序。在子序列建模中，由于失去了物理位置上的连续性锚点，我们无法再简单地通过延续或断开来转移状态。相反，问题的核心转变为在满足特定结构化限制的前提下，对每一个元素进行选或不选的决策平衡。

动态规划在处理此类问题时，通常通过维护一个或多个状态来刻画到当前位置为止的全局最优解。以经典的 **打家劫舍** 问题为例，子序列的选择受到相邻元素不能同时被选中这一限制。为了刻画这一结构约束，我们通常设 $dp[i]$ 表示考虑到第 $i$ 个位置时能获得的最大收益。每一步的转移都演化为一种博弈：如果选择当前位置的元素，则必须跳过前一个位置并继承 $dp[i-2]$ 的成果；如果不选当前位置，则直接继承 $dp[i-1]$ 的最优状态。

因此，子序列建模的本质是利用 **状态的组合** 来覆盖所有可能的非连续路径。有效的建模技巧源于对结构性限制的解构，通过在状态定义中引入跳跃或分支逻辑，我们能够利用历史状态的包容性进行转移，而无需受限于相邻位置的束缚。这种思想强调局部决策如何通过逻辑分支构成全局最优。理解了这种从连续延续到选择性跳跃的思维转变，便能应对更复杂的子序列约束问题，构造出具备跳跃逻辑的动规模型。

# 多区间累加和问题

多区间累加和问题通常可以根据 **区间长度相同** 与 **区间长度不同** 分为两类。这两类问题的核心区别在于区间自由度的差异：当长度固定时，每个区间仅由起点决定，结构相对规整；而当长度不固定时，区间的左右端点均可变化，状态设计与转移方式也随之变得更加复杂。

从建模逻辑上看，多区间累加和可以被视为 **子数组与子序列问题的综合版本** 。在单个区间内部，元素必须保持绝对连续，这继承了子数组的特性；而在区间之间，各段可以互不相邻，这又体现了子序列选择的灵活性。这种复合结构要求我们在状态转移时，既要处理好区间内部的连续性锚点，也要协调好区间之间的跳跃逻辑。

同时需要注意，多区间问题与单区间最大子数组问题在本质上存在显著差异。多区间问题必须显式地限制 **区间个数** ，否则逻辑就会退化为不限数量的子序列最大累加和。由于不限个数的子序列最大累加和只需简单地将所有正数相加即可，甚至比打家劫舍问题更加直观，因此正是区间个数受限这一核心条件，才使得此类问题具备了深入探讨动态规划建模的意义。

### 固定长度区间选取

在区间长度固定的场景下，假设每个区间的长度均为 $L$ ，且总共需要选取 $K$ 个区间。由于长度固定，任何合法的区间都可以唯一地由其右端点 $i$ 确定为 $[i-L+1, i]$ ，这使得问题的自由度仅剩下 **起点位置** 的选择。为了提高效率，我们可以先利用前缀和预处理出所有长度为 $L$ 的区间和，将原问题简化为在这些预设区间中寻找 $K$ 个互不重叠且总和最大的组合。

预处理阶段，通过前缀和数组 $pre$ 快速计算以 $i$ 为结尾的区间和 $w[i]$：

$$
w[i] = pre[i] - pre[i-L]
$$

在构建动态规划模型时，我们设 $dp[i][j]$ 表示在前 $i$ 个位置中选取 $j$ 个长度为 $L$ 的区间所能达到的最大累加和。此时，在每一个位置 $i$ 处，决策逻辑演化为对当前结尾区间的选与不选：

$$
dp[i][j] = \max\Big( dp[i-1][j], \, dp[i-L][j-1] + w[i] \Big)
$$

方程的第一项 $dp[i-1][j]$ 代表不选择以 $i$ 为结尾的区间，直接继承前一位置的最优结果；第二项则代表强制选择区间 $[i-L+1, i]$ ，由于区间长度为 $L$ ，为了保证不重叠，上一个区间的结束位置必须在 $i-L$ 之前。这种建模方式利用了区间长度固定的特性，使冲突范围变得极其确定，整体时间复杂度稳定在 $O(nK)$ 。

### 自由长度区间选取

相比之下，当区间长度不再固定时，尽管区间个数仍设为 $K$ ，但每个区间的左右端点 $[l, r]$ 均可自由选择，这显著增加了问题的自由度。我们设 $dp[i][j]$ 表示在前 $i$ 个位置中选取 $j$ 个互不重叠区间的最大总和。在处理位置 $i$ 时，决策逻辑在于：要么不以 $i$ 作为任何区间的结尾，直接继承状态；要么令第 $j$ 个区间在 $i$ 处结束，而该区间的左端点则需要在之前的某个位置确定。本质上，这是一个 **区间划分型动态规划问题** 。

若通过前缀和 $pre$ 进行初步建模，并枚举最后一个区间的起点 $t$，其转移方程可以表示为：

$$
dp[i][j] = \max\Big( dp[i-1][j], \, \max_{0 \leq t < i} \big( dp[t][j-1] + pre[i] - pre[t] \big) \Big)
$$

直接枚举起点 $t$ 会导致 $O(n^2K)$ 的计算复杂度，在处理大规模数据时效率较低。为了优化性能，我们可以将第二项的结构重新整理为：

$$
(dp[t][j-1] - pre[t]) + pre[i]
$$

观察可以发现，对于固定的区间个数 $j$ ，当 $i$ 向后扫描时，$pre[i]$ 是一个确定的偏移量，而我们需要寻找的是历史跨度中 $dp[t][j-1] - pre[t]$ 的最大值。因此，我们只需在扫描过程中实时维护一个变量 $best$：

$$
best = \max_{0 \le t < i} \big( dp[t][j-1] - pre[t] \big)
$$

此时，状态转移方程简化为：

$$
dp[i][j] = \max\big( dp[i-1][j], \, pre[i] + best \big)
$$

在每一步更新完 $dp[i][j]$ 后，随即利用当前的 $dp[i][j-1] - pre[i]$ 去更新 $best$ ，从而为后续位置的计算提供支持。通过这种方式，我们消除了对起点 $t$ 的显式枚举，使单次状态转移的时间复杂度降至 $O(1)$，整体复杂度也成功从 $O(n^2K)$ 优化至 $O(nK)$ 。这一优化的核心逻辑在于 **将区间枚举转化为历史最优值的增量维护** ，从而完成了从搜索型转移到常数级维护的结构升级。

# 划分动态规划问题

划分动态规划的核心在于将一个给定的序列或数组 **完整地** 划分为若干个连续的子段。这种建模范式要求数组中的每一个元素都必须属于且仅属于某一个子段，从而实现对原序列的无死角、完全覆盖。在这种结构下，全局最优解的递推逻辑表现为：当前位置 $i$ 的最优状态，是由前序某个位置 $t$ 的子问题解，与最后一段 $[t+1, i]$ 的贡献值衔接而成。

与 **多区间累加和问题**（允许选择性跳过元素、存在间隙）不同，划分 DP 强调的是元素分配的连续性与强制性。在多区间选取问题中，模型可以通过不选择某些元素来规避负收益或调整区间分布，但在划分 DP 的语境下，每一个元素都必须被纳入某个具体的段落中。这种强制性的全覆盖约束，使得划分 DP 在状态转移时具有极高的逻辑严密性，同时也为通过预处理区间代价或引入辅助变量来优化计算开销提供了结构基础。

### 最优型划分问题

最优划分型问题通常不限制划分的具体个数，其目标是寻找一种分割方案，使得最终的累积得分或总代价达到全局最优。在这类问题中，状态定义通常采用一维形式，$dp[i]$ 表示前 $i$ 个元素达成最优划分时的得分。由于段数 $k$ 是未知的，在处理位置 $i$ 时，需要枚举所有可能的最后一个切分点 $t$ ，从而从历史的最优状态完成状态转移：

$$
dp[i] = \text{opt}_{0 \leq t < i} \{ dp[t] \otimes cost(t+1, i) \}
$$

这种建模方式能够使算法根据 $cost$ 的函数特征，自动在 “细化切分” 与 “保持段落完整” 之间做出权衡。例如在单词拆分或最少回文分割等经典问题中，一维 $dp$ 能够通过对历史切分点的全扫描，确定出全局成本最低或得分最高的路径，从而揭示问题的最优分段结构。

### 约束型划分问题

划分约束型问题对 **划分次数 K** 进行了明确限制。对于 “至多划分为 $K$ 份” 的需求，在实际处理中可以直接将其转化为 “恰好划分为 $j$ 份（ $1 \leq j \leq K$ ）” 的逻辑进行求解。具体操作时，仅需按照恰好划分的流程计算出所有可能的段数结果，最后在结果收集阶段，从 $dp[n][1]$ 到 $dp[n][K]$ 中遍历并提取全局最优值。这种方式能够直接沿用恰好划分的核心框架，使研究重心集中于 **恰好划分为 K 份** 的模型。

在恰好划分为 $K$ 份的场景下，状态定义通常为二维：$dp[i][j]$ 表示前 $i$ 个元素被精确划分为 $j$ 段时的最优值。在进行状态转移时，通过枚举最后一个划分点 $t$ 的位置来推进：假设最后一段的范围是 $[t+1, i]$ ，那么前 $t$ 个元素必然已经构成了 $j-1$ 段。其状态转移方程如下：

$$
dp[i][j] = \text{opt}_{j-1 \leq t < i} \{ dp[t][j-1] \otimes cost(t+1, i) \}
$$

这种恰好划分的逻辑与前面提到的子数组选取 DP 在形式上非常接近，但核心区别在于 **状态继承项** 的处理。在选取类问题中，允许元素被舍弃，因此方程通常包含 $dp[i-1][j]$ ，代表当前位置可以不作为任何区间的结尾；但在 **划分 DP** 中，由于必须实现全覆盖，该项并不存在，每一个元素 $i$ 都必须作为第 $j$ 段的结尾，紧随在某个切分点 $t$ 之后。

当 $cost(t+1, i)$ 具备可拆分性（如区间累加和 $pre[i] - pre[t]$ ）时，该模型同样可以进行结构优化。通过将方程整理为关于 $t$ 的独立项与关于 $i$ 的偏移项，可以引入辅助变量 $best$ 来实时维护历史最优值：

$$
best = \max_{j-1 \leq t < i} \{ dp[t][j-1] - pre[t] \}
$$

此时，状态转移方程简化为 $dp[i][j] = pre[i] + best$ 。在扫描过程中，每一步更新完 $dp[i][j]$ 后，随即利用当前的 $dp[i][j-1] - pre[i]$ 去更新 $best$ ，从而为后续位置的计算提供支持。这种优化方式消除了对起点 $t$ 的显式枚举，使单次状态转移的时间复杂度降至 $O(1)$ ，整体复杂度也从 $O(n^2K)$ 降至 $O(nK)$ 。
