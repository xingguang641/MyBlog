# 划分动态规划问题

**划分动态规划** 是一类经典的动态规划模型，其核心在于将一个给定的序列或数组 **完整地** 划分为若干个连续的子段。与 “区间选取” 类问题（可以选择性跳过某些元素）不同，划分 DP 要求数组中的 **每一个元素都必须属于且仅属于某一个子段** ，从而实现对原序列的完全覆盖。这种 “无缝分段” 的结构使得全局最优解可以被分解为：前 $k$ 个元素的某种划分方案，加上最后一段 $[k+1, i]$ 的贡献。

在划分 DP 中，最通用的状态定义通常包含两个维度：

$$
dp[i][j]
$$

表示 **前 i 个元素被精确划分为 j 段时的最优值** 。这种定义方式直接对应了问题的分段本质。在进行状态转移时，我们通过枚举 “最后一个划分点” 的位置来推进：假设最后一段的范围是 $[k+1, i]$ ，那么前 $k$ 个元素必然已经被划分为 $j-1$ 段。基于此，状态转移方程通常表示为：

$$
dp[i][j] = \text{opt}_{j-1 \leq k < i} \{ dp[k][j-1] \otimes cost(k+1, i) \}
$$

其中 $\text{opt}$ 代表 $\max$ 或 $\min$ 操作，$\otimes$ 代表根据题目要求的运算（如加法、乘法等），而 $cost(l, r)$ 则表示将区间 $[l, r]$ 作为独立一段时产生的代价。由于必须包含所有元素，每一个 $dp[i][j]$ 的计算都在为最终覆盖全长度 $n$ 的 $dp[n][m]$ 铺路。

一种典型的应用是 **固定划分次数的分段问题** 。例如，给定一个数字字符串，要求插入 $k$ 个乘号将其划分为 $k+1$ 段，使得各段数值的乘积最大。在这种场景下，所有字符都必须参与运算，不能遗漏。为了提高效率，通常需要 **预处理区间值** ，例如提前计算出任意区间 $[l, r]$ 对应的整数值或区间和。通过这种方式，在 DP 转移时查询 $cost(l, r)$ 的复杂度可以降至 $O(1)$ ，从而保证整体复杂度维持在 $O(n^2k)$ 。

在处理大规模数据时，枚举划分点 $k$ 往往是性能瓶颈。如果题目中的 $cost$ 函数满足特定的数学性质（如 **四边形不等式** ），我们可以利用 **决策单调性** 来优化。这意味着随着 $i$ 的增加，最优划分点 $k$ 也会单调地向右移动，从而将搜索空间大幅压缩，使复杂度优化至 $O(nk)$。这种优化在解决如 “邮局设置” 或 “最小化划分平方和” 等所有元素必须参与的复杂划分问题时尤为有效。
