# MEX 区间构造问题

在很多与区间相关的构造问题中，MEX（Minimum Excluded Number） 经常作为核心约束出现。MEX 表示一个集合中 **没有出现的最小非负整数** 。例如集合 ${0, 1, 3}$ 的 MEX 为 $2$ ，因为 $0$ 和 $1$ 都已经出现，而最小未出现的整数是 $2$ 。

MEX 有一个非常重要的结构性质：如果某个区间的 MEX 等于 $i$ ，那么这个区间 **必须包含所有 $0, 1, 2, \dots, i-1$** ，同时 **不能包含 i** 。也就是说，MEX 的值实际上完全由这些较小数字的出现情况决定。只要区间中缺少其中任何一个数，MEX 就会变得更小；而一旦区间中出现了 $i$ ，MEX 就一定会大于 $i$ 。

从这个性质可以得到一个非常关键的结论：如果希望某个区间的 MEX 为 $i$ ，那么这个区间至少需要有 **i 个位置** 来容纳 $0, 1, \dots, i-1$ 这些数字，否则无论如何安排都不可能同时包含这些元素。因此在许多构造问题中，区间长度往往会直接限制 MEX 的大小。例如长度为 $k$ 的区间，其 MEX 一定不会超过 $k$ ，因为最多只能放下 $k$ 个不同的数。

在实际的构造题中，这个性质通常用来 **反推出区间结构** 。如果题目要求某些区间具有指定的 MEX，那么首先需要保证区间中能够容纳 $0 \sim mex-1$ 这些元素，然后再确保 MEX 本身不出现在该区间中。很多时候只要先确定这些关键数字的位置，其余元素就可以任意填充，从而完成整个构造。

因此可以把区间 MEX 构造问题理解为一种 **“强制出现 + 强制缺失” 的结构约束**：较小的数字必须全部出现，而 MEX 对应的数字必须完全避开。抓住这一点之后，很多看似复杂的 MEX 构造题实际上都会转化为对区间长度和元素分布的简单安排。

# MEX 序列计数问题

在许多与 MEX 相关的计数问题中，一个非常常见的思路是 **枚举 MEX 的取值**。由于 MEX 的定义具有很强的结构性质，如果某个集合或区间的 MEX 等于 $i$ ，那么一定满足两个条件：集合中必须包含所有 $0, 1, 2, \dots, i-1$ ，同时不能包含 $i$ 。因此在进行计数时，可以先假设 MEX 的值为 $i$ ，再根据这两个条件分析哪些结构是合法的，从而完成统计。

在实际计算时，一个常用的技巧是 **通过差分来计算 MEX 的数量** 。例如在路径或区间计数问题中，可以先统计包含某些固定元素的结构数量。设 $ans_i$ 表示 **包含所有 $0, 1, 2, \dots, i$ 的路径数**，那么就可以利用 MEX 的定义得到一个简单的关系：包含 $0 \sim i-1$ 的路径数减去包含 $0 \sim i$ 的路径数，恰好就是包含 $0 \sim i-1$ 但不包含 $i$ 的路径数，也就是 MEX 等于 $i$ 的路径数。

用公式表示就是：

$$
mex_i = ans_{i-1} - ans_i
$$

其中 $mex_i$ 表示 MEX 为 $i$ 的路径数量，而 $ans_i$ 表示同时包含 $0 \sim i$ 的路径数量。这样一来，只要能够计算出每个 $ans_i$ ，就可以通过相邻项的差值直接得到所有 MEX 的计数。

这种方法的本质是利用 MEX **前缀必须全部出现、当前位置必须缺失** 的结构，将原本直接统计 MEX 的问题转化为统计 **包含若干前缀元素的结构数量** 。由于前缀集合具有天然的嵌套关系 $[0,i] \subset [0,i+1]$ ，因此这些数量之间往往可以通过差分关系联系起来，从而大幅简化计数过程。这种 “枚举 MEX + 前缀计数 + 差分” 的思路在很多区间问题、树上路径问题中都会反复出现，是处理 MEX 计数问题时非常重要的一种技巧。
