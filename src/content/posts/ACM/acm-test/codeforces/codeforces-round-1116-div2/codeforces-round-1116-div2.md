## Problem D

> `连续段处理` &nbsp;&nbsp; `隔板法`

### Problem Statement

奈芙莲从不喜欢长久的告别。在珂朵莉出发执行下一个任务之前，她什么也没说，而是开始为她准备一条小丝带。

她把 $n$ 颗玻璃珠排成一排，准备将它们穿到丝带上。每颗珠子要么是白色的，要么是黑色的。一个二进制字符串 $s$ 表示它们的颜色：字符 `0` 表示白色珠子，字符 `1` 表示黑色珠子。

为了让排列不那么寻常，奈芙莲把它变成了一个小游戏。她可以执行以下操作任意次（可以为零次）：

- 选择两个索引 $l$ 和 $r$（ $1 \leq l \leq r \leq n$ ），满足当前字符串中 $s_l = s_r$ ，并翻转子串 $s_l s_{l+1} \ldots s_r$ 。

例如 $s = \texttt{00110}$ ，奈芙莲可以选择 $l = 1$ 和 $r = 5$ ，因为 $s_1 = s_5 = \texttt{0}$ 。操作后，字符串变为 $\texttt{01100}$ 。

请计算可以从 $s$ 获得的不同二进制字符串的数量对 $998 244 353$ 取模后的结果。

### Constraints

- $1 \leq t \leq 10^4$
- $1 \leq n \leq 10^6$
- 所有测试用例中 $n$ 的总和不超过 $10^6$

### Input

输入包含多个测试用例：

- 第一行包含一个整数 $t$ ，表示测试用例的数量。

> $t$
>
> $case_1$
>
> $case_2$
>
> $\ldots$
>
> $case_t$

- 对于每个测试用例：

    - 第一行包含一个整数 $n$ ，表示珠子的数量。
    - 第二行包含一个长度为 $n$ 的二进制字符串 $s$ ，表示珠子的颜色。

> $n$
>
> $s$

### Output

对于每个测试用例，输出一行一个整数，表示答案对 $998 244 353$ 取模后的结果。

## Solution

做这道题需要积累相应的经验，连续段的数量与相邻不同位置的数量线性相关：连续段数恰好等于相邻不同位置数加一。仔细观察题目中的条件，翻转满足 $s_l = s_r$ 的区间并不会改变相邻不同的位置数量，因此连续段数不变。

翻转 $s_l \ldots s_r$ 时，区间内部的相邻关系只是整体反序，相邻不同的数量不变，区间外部的字符没有移动，相邻关系也不受影响。真正可能变化的只有区间两端与外部相接的位置，但翻转后位置 $l$ 和 $r$ 上的字符仍然是原来的 $s_l$ 和 $s_r$ ，所以边界处是否相同也不会改变。于是整个字符串中相邻不同的位置总数不变，连续段数也不变。

接下来看翻转操作究竟会改变什么，考虑三个相邻的连续段，长度分别为 $A, B, C$ ，颜色分别为 $X, Y, X$ ：

$$
X^A Y^B X^C
$$

取第一段末尾 $x$ 个字符、整个第二段以及第三段开头 $y$ 个字符进行翻转。因为两端都是颜色 $X$ ，所以这次操作合法。翻转前这一段是 $X^x Y^B X^y$ ，翻转后变成 $X^y Y^B X^x$ ，于是三段的长度变化为：

$$
(A, B, C) \longrightarrow (A - x + y, \, B, \, C - y + x)
$$

其中 $x$ 和 $y$ 可以自由选取，因此中间那一段的长度保持不变，而两个同色段可以在保持长度为正的前提下任意搬运长度。于是问题转化为一个组合问题：给定字符串长度 $n$ 、$1$ 的个数 $k$ 、连续段数 $m$ 以及首字符 $s_1$ ，统计有多少个长度为 $n$ 的 01 串，满足 $1$ 的个数恰好为 $k$ ，连续段数恰好为 $m$ ，且首字符等于 $s_1$ 。

设由 $1$ 组成的连续段数为 $r_1$ ，由 $0$ 组成的连续段数为 $r_0$ 。由于颜色交替：

- 当 $s_1 = 0$ 时

$$
r_0 = \left \lceil \frac m2 \right \rceil = \frac{m + 1}{2} \quad r_1 = \left \lfloor \frac m2 \right \rfloor = \frac m2
$$

- 当 $s_1 = 1$ 时

$$
r_1 = \left \lceil \frac m2 \right \rceil = \frac{m + 1}{2} \quad r_0 = \left \lfloor \frac m2 \right \rfloor = \frac m2
$$

把 $k$ 个 $1$ 分给 $r_1$ 个连续段，每段至少一个，由隔板法有：

$$
\binom{k - 1}{r_1 - 1}
$$

把 $n - k$ 个 $0$ 分给 $r_0$ 个连续段，每段至少一个，由隔板法有：

$$
\binom{n - k - 1}{r_0 - 1}
$$

两个部分互相独立，每一种分配方式都唯一对应一个字符串，所以答案为：

$$
\binom{k - 1}{r_1 - 1} \binom{n - k - 1}{r_0 - 1} \pmod{998244353}
$$

时间复杂度为 $O(n)$ 统计连续段，组合数通过预处理阶乘和逆元做到 $O(1)$ 查询，总复杂度为 $O \left( \sum n + 10^6 \right)$ 。

```cpp frame="code" title="main.cpp"
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN = 1000000 + 5;
const int MOD = 998244353;
ll fact[MAXN], invfact[MAXN];

ll qpow(ll a, ll b) {
    ll res = 1;
    while (b) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

ll C(int n, int k) {
    if (k < 0 || k > n) return 0;
    return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD;
}

int main() {
    fact[0] = 1;
    for (int i = 1; i < MAXN; i++) {
        fact[i] = fact[i - 1] * i % MOD;
    }

    invfact[MAXN - 1] = qpow(fact[MAXN - 1], MOD - 2);
    for (int i = MAXN - 1; i >= 1; i--) {
        invfact[i - 1] = invfact[i] * i % MOD;
    }

    int T; cin >> T;
    while (T--) {
        int n; string s;
        cin >> n >> s;

        int k = 0;
        for (char c : s) {
            if (c == '1') k++;
        }

        int m = 1;
        for (int i = 1; i < n; i++) {
            if (s[i] != s[i - 1]) m++;
        }

        if (m == 1) {
            cout << 1 << '\n';
            continue;
        }

        int r1, r0;
        if (s[0] == '0') {
            r0 = (m + 1) / 2;
            r1 = m / 2;
        } else {
            r1 = (m + 1) / 2;
            r0 = m / 2;
        }

        ll ans = C(k - 1, r1 - 1) * C(n - k - 1, r0 - 1) % MOD;
        cout << ans << endl;
    }
}
```

## Problem E

### Problem Statement

这是一个运行两次的通信题。

在妖精仓库，妮戈兰为珂朵莉和威廉准备了一个不寻常的游戏。他们将被分开，无法交流任何一个字。他们之间只有一张黑白图像：一张妮戈兰可以平移、旋转、翻转甚至反转颜色的图像。

两名玩家分别是珂朵莉和威廉。代表妮戈兰的裁判首先与珂朵莉通信，珂朵莉完成后，裁判与威廉通信。珂朵莉和威廉可以预先约定使用的策略，但他们不能直接互相传递信息。

在每个测试用例中，妮戈兰准备了一张由 $n \times n$ 个单元格组成的黑白图像，并选择了一个目标单元格 $x$ 。行和列从 $1$ 到 $n$ 编号。图像包含 $w$ 个黑色单元格。保证 $\gcd(n, w) = 1$ 。

妮戈兰首先将图像和目标单元格 $x$ 展示给珂朵莉。珂朵莉必须选择两个单元格并交换它们的颜色。这两个单元格可以是同一个。如果它们是同一个，或者它们颜色相同，图像不会改变。她不能向威廉发送任何其他信息。

交换颜色 **不会移动** 目标单元格。

然后妮戈兰秘密地变换图像，她可以按任意顺序执行以下操作任意次（可以为零次）：

1. 选择两个整数 $d_r$ 和 $d_c$ 并循环平移图像，每个单元格 $(r, c)$ 移动到：
    
    $$
    \big((r - 1 + d_r) \, \% \, n + 1, \, (c - 1 + d_c) \, \% \, n + 1 \big)
    $$

2. 将图像顺时针旋转 $90^\circ$ ，这样一次旋转会将每个单元格 $(r, c)$ 移动到 $(c, n + 1 - r)$ 。
3. 将图像沿垂直轴翻转，这样一次翻转会将每个单元格 $(r, c)$ 移动到 $(r, n + 1 - c)$ 。
4. 反转所有颜色，这将每个黑色单元格变为白色单元格，每个白色单元格变为黑色单元格。

目标单元格 $x$ 以与图像完全相同的方式经历每次循环平移、旋转和翻转，颜色反转不会移动它。

最后妮戈兰只将最终得到的图像展示给威廉，威廉必须确定 $x$ 的最终位置。

你的程序在每个测试中将被精确运行两次。在第一次运行时，它必须充当珂朵莉。在第二次运行时，它必须充当威廉。两次运行之间除了裁判根据上述规则传递的信息外，不保留任何信息。

测试用例的顺序在两次运行之间可能会改变。

### Constraints

- $1 \leq t \leq 10^4$
- $2 \leq n \leq 800$
- 所有测试用例中 $n^2$ 的总和不超过 $800^2$

### Input
