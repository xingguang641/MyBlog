## Problem D

### Problem Statement

奈芙莲从不喜欢长久的告别。在珂朵莉出发执行下一个任务之前，她什么也没说，而是开始为她准备一条小丝带。

她把 $n$ 颗玻璃珠排成一排，准备将它们穿到丝带上。每颗珠子要么是白色的，要么是黑色的。一个二进制字符串 $s$ 表示它们的颜色：字符 `0` 表示白色珠子，字符 `1` 表示黑色珠子。

为了让排列不那么寻常，奈芙莲把它变成了一个小游戏。她可以执行以下操作任意次（可以为零次）：

- 选择两个索引 $l$ 和 $r$（ $1 \leq l \leq r \leq n$ ），满足当前字符串中 $s_l = s_r$ ，并翻转子串 $s_l s_{l+1} \ldots s_r$ 。

例如 $s = \texttt{00110}$ ，奈芙莲可以选择 $l = 1$ 和 $r = 5$ ，因为 $s_1 = s_5 = \texttt{0}$ 。操作后，字符串变为 $\texttt{01100}$ 。

请计算可以从 $s$ 获得的不同二进制字符串的数量对 $998 244 353$ 取模后的结果。

### Constraints

- $1 \leq t \leq 10^4$
- $1 \leq n \leq 10^6$
- 所有测试用例中 $n$ 的总和不超过 $10^6$

### Input

输入包含多个测试用例：

- 第一行包含一个整数 $t$ ，表示测试用例的数量。

> $t$
>
> $case_1$
>
> $case_2$
>
> $\ldots$
>
> $case_t$

- 对于每个测试用例：

    - 第一行包含一个整数 $n$ ，表示珠子的数量。
    - 第二行包含一个长度为 $n$ 的二进制字符串 $s$ ，表示珠子的颜色。

> $n$
>
> $s$

### Output

对于每个测试用例，输出一行一个整数，表示答案对 $998 244 353$ 取模后的结果。

### Sample Input

```txt showLineNumbers=false
4
5
00110
6
001010
5
01010
6
111111
```

### Sample Output

```txt showLineNumbers=false
2
3
1
1
```

## Problem E

### Problem Statement

这是一个运行两次的通信题。

在妖精仓库，妮戈兰为珂朵莉和威廉准备了一个不寻常的游戏。他们将被分开，无法交流任何一个字。他们之间只有一张黑白图像：一张妮戈兰可以平移、旋转、翻转甚至反转颜色的图像。

两名玩家分别是珂朵莉和威廉。代表妮戈兰的裁判首先与珂朵莉通信，珂朵莉完成后，裁判与威廉通信。珂朵莉和威廉可以预先约定使用的策略，但他们不能直接互相传递信息。

在每个测试用例中，妮戈兰准备了一张由 $n \times n$ 个单元格组成的黑白图像，并选择了一个目标单元格 $x$ 。行和列从 $1$ 到 $n$ 编号。图像包含 $w$ 个黑色单元格。保证 $\gcd(n, w) = 1$ 。

妮戈兰首先将图像和目标单元格 $x$ 展示给珂朵莉。珂朵莉必须选择两个单元格并交换它们的颜色。这两个单元格可以是同一个。如果它们是同一个，或者它们颜色相同，图像不会改变。她不能向威廉发送任何其他信息。

交换颜色 **不会移动** 目标单元格。

然后妮戈兰秘密地变换图像，她可以按任意顺序执行以下操作任意次（可以为零次）：

1. 选择两个整数 $d_r$ 和 $d_c$ 并循环平移图像，每个单元格 $(r, c)$ 移动到：
    
    $$
    \big((r - 1 + d_r) \, \% \, n + 1, \, (c - 1 + d_c) \, \% \, n + 1 \big)
    $$

2. 将图像顺时针旋转 $90^\circ$ ，这样一次旋转会将每个单元格 $(r, c)$ 移动到 $(c, n + 1 - r)$ 。
3. 将图像沿垂直轴翻转，这样一次翻转会将每个单元格 $(r, c)$ 移动到 $(r, n + 1 - c)$ 。
4. 反转所有颜色，这将每个黑色单元格变为白色单元格，每个白色单元格变为黑色单元格。

目标单元格 $x$ 以与图像完全相同的方式经历每次循环平移、旋转和翻转，颜色反转不会移动它。

最后妮戈兰只将最终得到的图像展示给威廉，威廉必须确定 $x$ 的最终位置。

你的程序在每个测试中将被精确运行两次。在第一次运行时，它必须充当珂朵莉。在第二次运行时，它必须充当威廉。两次运行之间除了裁判根据上述规则传递的信息外，不保留任何信息。

测试用例的顺序在两次运行之间可能会改变。

### Constraints

- $1 \leq t \leq 10^4$
- $2 \leq n \leq 800$
- 所有测试用例中 $n^2$ 的总和不超过 $800^2$

### Input

输入包含多行：

- 第一行包含一个字符串，指示当前的运行状态：

    - 在第一次运行时，第一行为字符串 `first` 。
    - 在第二次运行时，第一行为字符串 `second` 。

- 第二行包含一个整数 $t$ ，表示测试用例的数量。

> `string`
>
> $t$
>
> $case_1$
>
> $case_2$
>
> $\ldots$
>
> $case_t$

- 对于每个测试用例：

    - 在第一次运行时：

        - 第一行包含一个整数 $n$ ，表示图像的高度和宽度。
        - 接下来 $n$ 行，每行包含一个长度为 $n$ 的字符串。字符 `#` 表示黑色格，字符 `.` 表示白色格。
        - 接下来一行包含两个整数 $r_x$ 和 $c_x$（ $1 \leq r_x, c_x \leq n$ ），表示目标单元格 $x$ 的行和列。

    > $n$
    >
    > $row_1$
    >
    > $row_2$
    >
    > $\ldots$
    >
    > $row_n$
    >
    > $r_x \quad c_x$

    - 在第二次运行时：

        - 第一行包含一个整数 $n$ ，表示图像的高度和宽度（测试用例顺序可能与第一次运行不同）。
        - 接下来 $n$ 行，每行包含一个长度为 $n$ 的字符串，表示经过珂朵莉和妮戈兰变换后得到的图像。

    > $n$
    >
    > $row_1$
    >
    > $row_2$
    >
    > $\ldots$
    >
    > $row_n$

### Output

在第一次运行时，对于每个测试用例，输出四个整数 $r_1, c_1, r_2, c_2$（ $1 \leq r_1, c_1, r_2, c_2 \leq n$ ），表示珂朵莉选择交换颜色的两个单元格的坐标，允许选择同一个单元格。在第二次运行时，对于每个测试用例，输出两个整数 $r'_x$ 和 $c'_x$（ $1 \leq r'_x, c'_x \leq n$ ），表示经过所有变换后目标单元格 $x$ 的最终行和列。
