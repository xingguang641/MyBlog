## Problem N

### Problem Statement

给定一个长度为 $n$ 的数组 $a$ 。一次操作中，你可以选择数组中的任意 $k$ 个元素，并将这 $k$ 个元素全部替换为它们的中位数。你必须恰好执行一次操作，请求出操作后数组所有元素之和的最大值。

### Constraints

- $1 \leq T \leq 10^4$
- $1 \leq k \leq n \leq 2 \times 10^5$
- $1 \leq a_i \leq 10^9$
- 所有测试用例中 $n$ 的总和不超过 $2 \times 10^5$

### Input

输入包含多个测试用例：

- 第一行包含一个整数 $T$ ，表示测试用例的数量。

> $T$
>
> $case_1$
>
> $case_2$
>
> $\ldots$
>
> $case_T$

- 对于每个测试用例：

  - 第一行包含两个整数 $n$ 和 $k$ ，分别表示数组长度和选择元素的数量。
  - 第二行包含 $n$ 个整数，表示数组中的元素。

> $n \quad k$
>
> $a_1 \quad a_2 \quad \ldots \quad a_n$

### Output

对于每个测试用例，输出一行一个整数，表示执行一次操作后数组元素和的最大值。

### Sample Input

```txt showLineNumbers=false
2
6 3
1 1 4 5 1 4
4 2
1 3 6 10
```

### Sample Output

```txt showLineNumbers=false
19
20
```

## Solution

枚举中位数，前半部分尽量小，变大之后收益就大，后半部分尽量小，变小之后亏损就小

```cpp frame="code" title="main.cpp"
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN = 2e5 + 100;
ll a[MAXN], s[MAXN];

int main(){
    int T; cin >> T;
    while(T--){
        int n, k; cin >> n >> k;
        for(int i = 1; i <= n; i++) cin >> a[i];
        sort(a + 1 , a + n + 1);
        for(int i = 1; i <= n; i++) s[i] = s[i - 1] + a[i];

        ll ans = 0;
        if (k % 2 == 1){
            int half = (k + 1) / 2;
            for (int i = half; i + k - half <= n; i++){
                ll leftSum = s[half - 1];
                ll rightSum = s[i + k - half] - s[i - 1];
                ll cur = s[n] + k * a[i] - leftSum - rightSum;
                ans = max(ans, cur);
            }
        }else{
            int half = k / 2;
            for (int i = half; i + half <= n; i++){
                ll leftSum = s[half - 1];
                ll rightSum = s[i + half] - s[i - 1];
                ll cur = s[n] + k * (a[i] + a[i + 1]) / 2 - leftSum - rightSum;
                ans = max(ans, cur);
            }
        }

        cout << ans << endl;
    }
}
```

## Problem B

### Problem Statement

给定一个非负整数数组 $a$ ，你需要将数组中的所有元素分配到两个空的多重集合 $A$ 和 $B$ 中。

最终得分为两个多重集合异或值之和：

### Constraints

- $1 \leq n \leq 5 \times 10^5$
- $0 \leq a_i < 2^{30}$
- 所有测试用例中 $n$ 的总和不超过 $5 \times 10^5$

### Input

输入包含多个测试用例：

  - 第一行包含一个整数 $n$ ，表示数组长度。
  - 第二行包含 $n$ 个整数，表示数组中的元素。

> $n$
>
> $a_1 \quad a_2 \quad \ldots \quad a_n$

### Output

对于每个测试用例，输出一行一个整数，表示可以得到的最大得分。

### Sample Input

```txt showLineNumbers=false

3

4

```

### Sample Output


## Solution

设最终两个多重集合 $A$ 和 $B$ 的异或值分别为 $X$ 和 $Y$ ，整个数组的异或和为 $S$ 。由于所有元素恰好被分配到其中一个集合，因此有 $X \oplus Y = S$ ，我们的目标是最大化 $X + Y$ 。

对于任意两个非负整数 $X, Y$ ：

$$
X + Y = (X \oplus Y) + 2 \, (X \, \& \, Y)
$$

代入 $X \oplus Y = S$ 可以得到：

$$
X + Y = S + 2 \, (X \, \& \, Y)
$$

由于 $S$ 已经固定，问题等价于最大化 $X \, \& \, Y$ 。

接下来考虑 $S$ 的每一位二进制。如果 $S$ 的某一位为 $1$ ，那么 $X$ 和 $Y$ 在这一位一定不同，$X \, \& \, Y$ 的这一位必然为 $0$ ，不会对答案产生贡献。因此可以忽略 $S$ 中为 $1$ 的位，对于每个 $a_i$ ，只保留 $S$ 中对应为 $0$ 的部分：

$$
b_i = a_i \, \& \, \sim S
$$

假设选择一些元素放入集合 $A$ ，其余元素放入集合 $B$ 。记选择出的元素在保留位上的异或结果为：

$$
Z = \bigoplus_{i \in A} b_i
$$

由于保留下来的二进制位在 $S$ 中均为 $0$ ，而 $X \oplus Y = S$ ，所以在这些位上 $X$ 和 $Y$ 必然相同。也就是说，如果 $A$ 的异或结果在某一位为 $1$ ，那么 $B$ 的异或结果在这一位也一定为 $1$ ，此时这一位就会对 $X \, \& \, Y$ 产生贡献，于是 $X \, \& \, Y$ 在这些位上的值恰好等于 $A$ 选出元素的异或结果 $Z$ 。

原问题便转化为从数组 $b_1, \, b_2, \, \ldots, \, b_n$ 中选择一个异或和最大的子集，可以使用异或线性基解决。

维护一个长度为 $30$ 的线性基，其中第 $i$ 位存储最高位为 $i$ 的基向量。依次插入每个 $b_i$ ，插入时从高位到低位消去当前数的最高位。如果该位置已经存在基向量，就将当前数与其异或，否则将当前数作为新的基向量。

构造完线性基后，从高位到低位贪心计算最大异或值。设当前结果为 $ans$ ，对于每个基向量 $basis[i]$ ，如果满足 $ans \oplus basis_i > ans$ ，那么将其加入答案，最终得到的 $ans$ 就是所有子集异或和中的最大值。

设这个最大值为 $mx$ ，那么根据前面的推导，最终答案为：

$$
S + 2 \, mx
$$

由于每个数插入线性基时最多处理 $30$ 个二进制位，因此每个测试用例的时间复杂度为 $O(30n)$ ，空间复杂度为 $O(30)$ 。所有测试用例的 $n$ 总和不超过 $5 \times 10^5$ ，整体复杂度可以满足题目的要求。

## Problem L

### Problem Statement

Sean 被要求对长度为 $n$ 的排列进行洗牌。一个排列是长度为 $n$ 且包含 $1$ 到 $n$ 中每个数字恰好一次的整数序列。

他的主管通过比较洗牌前后排列的逆序对数量来检查他的工作，即定义一个排列 $A$ 的逆序对数量为：

$$
f(A) = \sum_{1 \leq i < j \leq n} \mathbb{1}_{A_i > A_j}
$$

假设洗牌前后的排列分别为 $A$ 和 $A'$ ，主管通过计算以下值来检查 Sean 的工作：

$$
g(A, A') = |f(A) - f(A')|
$$

主管希望这个值尽可能大。

但是 Sean 很懒，他并不想真正去洗牌。因此他决定使用一个固定长度为 $n$ 的排列 $p = [p_1, p_2, \ldots, p_n]$ ，当遇到一个排列 $A = [A_1, A_2, \ldots, A_n]$ 时，他直接提交 $f_p(A) = [A_{p_1}, A_{p_2}, \ldots, A_{p_n}]$ 作为洗牌结果。

若 Sean 使用上述洗牌方法，当且仅当排列 $A$ 使得 $g(A, f_p(A))$ 达到最大值时称排列 $A$ 为一个 **幸运排列** 。也就是说，对于任意长度为 $n$ 的排列 $A_0$ ，均满足 $g(A, f_p(A)) \geq g(A_0, f_p(A_0))$ 。

请求出有多少个幸运排列？由于答案可能很大，输出其对 $998 244 353$ 取模后的结果。

### Constraints

- $1 \leq n \leq 22$
- $1 \leq p_i \leq n$

### Input

输入包含两行：

- 第一行包含一个整数 $n$ ，表示排列的长度。
- 第二行包含 $n$ 个整数 $p_1, \, p_2, \, \ldots, \, p_n$ ，表示 Sean 用来洗牌的排列 $p$ 。

> $n$
>
> $p_1 \quad p_2 \quad \ldots \quad p_n$

### Output

输出一个整数，表示幸运排列的数量对 $998 244 353$ 取模后的结果。

### Sample Input 1

```txt showLineNumbers=false
3
3 1 2
```

### Sample Output 1

```txt showLineNumbers=false
4
```

### Sample Input 2

```txt showLineNumbers=false
3
3 2 1
```

### Sample Output 2

```txt showLineNumbers=false

```

## Solution

设原排列为 $A$ ，洗牌后的排列为 $f_p(A)$ 。观察题目中的 $f(A) - f(f_p(A))$ ，它表示排列 $A$ 在洗牌前后逆序对数量的变化，也就是 **相对逆序对数** ，题目要求最大化其绝对值，即最大化 $\left|f(A) - f(f_p(A)) \right|$ 。

接下来考虑任意两个位置 $i$ 和 $j$ ，假设在原排列 $A$ 中，位置 $i$ 与位置 $j$ 的先后关系为 $i < j$ ，洗牌后这两个位置上的元素分别移动到新排列中的第 $p_i^{-1}$ 和第 $p_j^{-1}$ 个位置。

如果 $p_i^{-1} < p_j^{-1}$ ，说明这两个位置在洗牌前后的相对顺序没有发生变化，因此它们在两个排列中的逆序情况相同，对相对逆序对数没有贡献。如果 $p_i^{-1} > p_j^{-1}$ ，说明这两个位置在洗牌后发生了相对位置的翻转。

当 $A_i > A_j$ 时，这两个元素在 $A$ 中构成逆序对，而在 $f_p(A)$ 中不构成逆序对，贡献为 $1$ ；当 $A_i < A_j$ 时，这两个元素在 $A$ 中不构成逆序对，而在 $f_p(A)$ 中构成逆序对，贡献为 $-1$ 。

因此真正影响相对逆序对数的只有满足 $i < j$ 且 $p_i^{-1} > p_j^{-1}$ 的位置对，我们可以将这些位置对看作 $p$ 中的逆序关系并建立一张图，每个位置对应一个顶点，对于满足上述条件的两个位置连一条边。

现在考虑一个排列 $A$ ，我们可以按照元素从小到大的顺序，依次确定它们在排列中的位置。也就是说，我们先确定数字 $1$ 放在哪个位置，再确定数字 $2$ 放在哪个位置，依次处理到数字 $n$ 。

假设当前处理到数字 $k$ ，由于前面处理的都是比 $k$ 更小的数字，所以 $k$ 一定是当前处理的最大数字。确定 $k$ 的位置后，它与已放置元素之间的大小关系也随之确定，因此可以直接计算这些位置对产生的贡献。

对于图中的一条边 $(i, j)$ ，当顶点 $j$ 比顶点 $i$ 更早加入时，位置 $j$ 上的元素更小，这条边对相对逆序对数的贡献为 $1$ ；当顶点 $i$ 比顶点 $j$ 更早加入时，位置 $i$ 上的元素更小，这条边对相对逆序对数的贡献为 $-1$ 。因此只要确定所有顶点的加入顺序，就可以唯一确定每条边的贡献，也就可以得到相对逆序对数。

由于 $n \leq 22$ ，可以使用状压 DP 解决该问题。令 $S$ 表示 **当前已经被占用的位置** ，由于我们按照数字从小到大的顺序依次确定位置，所以当 $|S| = k$ 时，恰好表示数字 $1, \, 2, \, \dots, \, k$ 已经分别放入了 $S$ 中的这些位置。

例如当 $S = \{2, 4\}$ 时，表示数字 $1, 2$ 已经放入位置 $2, 4$ ，也就是这两个位置已经被占用。此时 $S$ 本身只是一个集合，并不记录数字 $1, 2$ 分别放在哪个位置，这些不同的放置顺序会作为不同的方案合并到同一个状态中。

令 $dp[S]$ 表示处理完数字 $1, \, 2, \, \dots, \, |S|$ 后，在所有可能的放置方案中，已经确定的这些元素所产生的最大相对逆序对数，也就是当前状态 $S$ 能够取得的最大贡献。同时维护 $cnt[S]$ ，表示达到 $dp[S]$ 的放置方案数量。

考虑从状态 $S$ 中选择一个还未被占用的位置 $v$ ，将当前数字 $|S| + 1$ 放到位置 $v$ 。根据前面的讨论，只有在图中存在边的位置对才会产生贡献，因此只需要计算 $v$ 与 $S$ 中相邻顶点产生的贡献。设 $c_1$ 为 $S$ 中与 $v$ 相连且编号大于 $v$ 的顶点数量，$c_2$ 为 $S$ 中与 $v$ 相连且编号小于 $v$ 的顶点数量，则新增贡献为 $c_1 - c_2$ 。

将数字 $|S| + 1$ 放入位置 $v$ 后，得到新状态 $S \cup \{v\}$ ，对应的相对逆序对数为：

$$
dp[S] + c_1 - c_2
$$

由于 $dp\big[S \cup \{v\} \big]$ 只保留该状态下的最大值，因此：

- 当 $dp[S] + c_1 - c_2 > dp\big[S \cup \{v\} \big]$ 时，更新 $dp\big[S \cup \{v\} \big]$ ，并令 $cnt\big[S \cup \{v\} \big] = cnt[S]$ 。
- 当 $dp[S] + c_1 - c_2 = dp\big[S \cup \{v\} \big]$ 时，将 $cnt[S]$ 累加到 $cnt\big[S \cup \{v\} \big]$ 中。

为了快速计算 $c_1$ 和 $c_2$ ，可以预处理每个顶点的邻接集合，并通过二进制进行压缩。对于状态 $S$ ，通过位运算求交集并统计其中 $1$ 的数量，就能在 $O(1)$ 时间内计算新增的贡献。最终 $dp[(1 << n) - 1]$ 即为最大相对逆序对数 $M$ ，而 $cnt[(1 << n) - 1]$ 则表示取得 $M$ 的排列数量。

不过本题还需考虑如何处理绝对值。如果将一个排列 $A$ 中所有元素的大小关系反转，每一对元素的大小关系都会发生反转，因此每条边产生的贡献也都会反转。也就是说，取得 $-M$ 的排列数量与取得 $M$ 的排列数量相同。

当 $M > 0$ 时，两部分排列互不相同，所以幸运排列数量为：

$$
2 \times cnt[(1 << n) - 1]
$$

如果 $M = 0$ ，则相对逆序对数的最大值和最小值均为 $0$ ，所有排列都是幸运排列，因此答案为 $n!$ 。

## Problem F

### Problem Statement

给定一棵包含 $n$ 个节点且以 $1$ 为根的树，树上的每条边均被赋予了一个非负整数数边权。对于节点 $u$ 和 $v$ 之间的边，其边权记为 $w_{u, v}$ 。你需要为树上的每个节点 $u$ 分配一个非负整数 $a_u$ ，如果对于树上每一条边 $(u, v)$ ，均满足 $w_{u, v} = |a_u - a_v|$ ，则称这棵树是 **绝妙的** 。

对于一棵绝妙的树，定义其 **复杂度** 为树中所有节点点权的最大值与最小值之差。

现在节点点权缺失，对于每个 $i$（ $1 \leq i \leq n$ ），假设只考虑以 $i$ 为根的子树，你需要为该子树中的节点分配非负整点权，使其成为一棵绝妙的树，求此时该子树复杂度的最小值。

### Constraints

- $1 \leq T \leq 10^4$
- $3 \leq n \leq 10^5$
- $1 \leq u_i, v_i \leq n$
- $0 \leq w_{u_i, \, v_i} \leq 5000$
- 所有测试用例中 $n$ 的总和不超过 $\displaystyle \min \left(\frac{3 \times 10^7}{\max(1, W)}, 10^5 \right)$

### Input

输入包含多个测试用例：

- 第一行包含一个整数 $T$ ，表示测试用例的数量。

> $T$
>
> $case_1$
>
> $case_2$
>
> $\ldots$
>
> $case_T$

- 对于每个测试用例：

    - 第一行包含一个整数 $n$ ，表示树的节点数量。
    - 接下来 $n - 1$ 行，第 $i$ 行包含三个整数 $u_i$ 、$v_i$ 和 $w_{u_i, \, v_i}$ 。

> $n$
>
> $u_1 \quad v_1 \quad w_{u_1, v_1}$
>
> $u_2 \quad v_2 \quad w_{u_2, v_2}$
>
> $\ldots$
>
> $u_{n - 1} \quad v_{n - 1} \quad w_{u_{n - 1}, v_{n - 1}}$

### Output

对于每个测试用例，输出一行包含 $n$ 个整数，表示以节点 $1, 2, \ldots, n$ 为根的子树在成为绝妙的树时的答案。

## Solution

由于边的限制只有 $w_{u, v} = |a_u - a_v|$ ，而把所有 $a_u$ 同时加上一个相同的数并不会改变任何边的限制，也不会改变 $\max a_u - \min a_u$ ，因此对于以 $u$ 为根的子树，我们可以固定 $a_u = V$ ，只考虑其他节点相对于 $V$ 的大小。假设这棵子树中的所有点都落在区间 $[V - i, \, V + j]$ 内，那么它的复杂度就是 $i + j$ 。

我们可以将 $i$ 和 $j$ 作为状态的一部分，定义 $dp[u][i][j]$ 表示在 $a_u = V$ 的情况下，能否将以 $u$ 为根的子树放入区间 $[V - i, \, V + j]$ 内。由于边权最大为 $W$ ，因此 $i$ 和 $j$ 只需要考虑 $O(W)$ 范围内的取值，对于每个 $u$ 则需要维护 $O(W^2)$ 个状态，使得整个 DP 的时间复杂度达到 $O(nW^2)$ ，无法正常通过本题。

仔细观察这个状态设计，每个状态实际上只记录一个 0/1 值，信息利用率较低，因此还有进一步压缩的空间。

注意到我们最终只关心 $i + j$ ，因此可以将其中一维压入状态值中。具体来说，对于每个固定的 $i$ ，我们只需要保留满足条件的最小 $j$ ，于是将原来的 0/1 状态转化为：

$$
dp[u][i] = j
$$

其中 $dp[u][i]$ 表示固定 $i$ 时，使以 $u$ 为根的子树能够放入区间 $[V - i, \, V + j]$ 的最小 $j$ 。这样便将原来的两维状态压缩为一维，同时利用状态值保存了被压缩的另一维信息。最终以 $u$ 为根的子树的答案为：

$$
ans_u = \min_i{i + dp[u][i]}
$$

接下来考虑 $u$ 的一个儿子 $v$ ，设边权为 $w$ 。根据 $w = |a_u - a_v|$ 这个限制，$a_v$ 只有两种可能：

- 如果选择 $a_v = V + w$ ，由于整个子树不能低于 $V - i$ ，所以相对于 $a_v$ ，向下最多可以延伸 $i + w$ ，对应状态 $dp[v][i + w]$ 。因此以 $V$ 为基准时，子树的最高位置为 $w + dp[v][i + w]$ 。

- 如果选择 $a_v = V - w$ ，则需要满足 $V - w \geq V - i$ ，此时相对于 $a_v$ ，向下最多可以延伸 $i - w$ ，对应状态 $dp[v][i - w]$ 。因此以 $V$ 为基准时，子树的最高位置为 $-w + dp[v][i - w]$ 。


因此对于儿子 $v$ ，在当前 $i$ 下能够取得的最小贡献为：

$$
\operatorname{trans}(v, i) = \min \left(w + dp[v][i + w], \, -w + dp[v][i - w] \right)
$$

不同儿子的取值可以独立决定，因此只需要分别考虑每个儿子能够取得的最小贡献。由于整个子树的最高位置必须覆盖所有儿子子树，同时还需要包含节点 $u$ 自身的位置 $V$ ，所以最终应在所有儿子中取最大值：

$$
dp[u][i] =
\max \left(0, \,
\max_{v \in \operatorname{child}(u)}
\operatorname{trans}(v, i)
\right)
$$

只需要考虑 $0 \leq i \leq 2W - 1$ 的状态，其中 $W$ 是所有边权的最大值。因此每个节点有 $O(W)$ 个状态，每条边需要处理 $O(W)$ 次，整个 DP 的时间复杂度为 $O(nW)$ ，空间复杂度为 $O(nW)$ 。
