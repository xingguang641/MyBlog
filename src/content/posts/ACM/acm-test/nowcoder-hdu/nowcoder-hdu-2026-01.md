## Problem F

### Problem Statement

对于一个由 $0$ 到 $n - 1$ 组成的排列 $P$ ，定义其价值为：

$$
f(P) = \sum_{0 \leq i < j < n} (P_j - P_i)
$$

给定一个由 $0$ 到 $n - 1$ 组成的排列 $P$ ，以及两个整数 $k$ 和 $x$ 。

请构造一个排列 $P'$ ，满足：

- $P'_k = x$ ，即下标为 $k$ 的位置上的元素为 $x$（下标从 $0$ 开始）
- $f(P') \equiv f(P) \pmod n$

如果存在满足条件的排列 $P'$ ，输出任意一个合法排列。如果不存在，输出 $-1$ 。

### Constraints

- $1 \leq n \leq 2 \times 10^5$
- $0 \leq k, x < n$

### Input

输入包含两行：

- 第一行包含三个整数 $n$ 、$k$ 和 $x$ 。
- 第二行包含 $n$ 个整数 $P_0, P_1, \ldots, P_{n - 1}$ ，表示给定的排列。

> $n \quad k \quad x$
>
> $P_0 \quad P_1 \quad \ldots \quad P_{n - 1}$

### Output

如果不存在满足条件的排列，输出一个整数 `-1` ；否则输出一行包含 $n$ 个整数，表示构造出的排列 $P'$ 。

### Sample Input

```txt showLineNumbers=false
4 1 3
2 0 1 3
```

### Sample Output

```txt showLineNumbers=false
0 3 1 2
```

## Solution

由于公式中的 $P_j - P_i$ 实际上记录的是两个元素之间的 **相对信息** ，因此对所有元素同时增加一个相同的数并不会改变这种相对信息。对所有元素同时增加常数 $c$ ，两个元素之间的差值保持不变：

$$
(P_j + c) - (P_i + c) = P_j - P_i
$$

因此直接对所有元素同时增加一个常数，就可以调整元素值的同时保持 $f(P)$ 不变。但这样变换后并不能保证所有元素仍在 $0$ 到 $n - 1$ 的范围内，因此 **无法得到** 一个合法排列。

注意到题目要求构造出的排列需要满足：

$$
f(P') \equiv f(P) \pmod n
$$

由于模 $n$ 运算不会影响这种相对信息在模 $n$ 意义下的结果，因此可以令：

$$
P'_i = (P_i + c) \bmod n
$$

这样得到的 $P'$ 仍然是一个排列，并且对于任意 $i < j$ 都有：

$$
P'_j - P'_i \equiv P_j - P_i \pmod n
$$

接下来需要选择合适的常数 $c$ 使第 $k$ 个位置上的元素变为 $x$ ：

$$
P'_k = (P_k + c) \bmod n = x
$$

为了使上式成立，需要令：

$$
c = (x - P_k + n) \bmod n
$$

将这个常数应用到所有元素上，即可按照相同的规则构造出新的排列，并同时满足题目中的两个条件。整个构造过程只需要遍历一次排列，因此时间复杂度为 $O(n)$ ，空间复杂度为 $O(n)$ 。

如果将公式中的减法改成加法，例如定义：

$$
g(P) = \sum_{0 \leq i < j < n} (P_j + P_i)
$$

此时对所有元素同时增加 $c$ ，每一对元素的贡献都会增加 $2c$ 。由于一共有 $C_n^2$ 对元素，因此总增量为：

$$
2c \times C_n^2 = 2c \times \frac{n (n - 1)}{2} = c n (n - 1)
$$

这个增量是 $n$ 的倍数，因此有：

$$
g(P') \equiv g(P) \pmod n
$$

也就是说，加法形式下整体增加常数虽然会改变函数值，但变化量是 $n$ 的倍数，因此模 $n$ 意义下仍保持不变。

```cpp frame="code" title="main.cpp"
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 2e5 + 100;
int n, k, x; int arr[MAXN];

int main() {
    cin >> n >> k >> x;
    for (int i = 0; i < n; i++){
        cin >> arr[i];
    }
    
    int d = ((x - arr[k]) % n + n) % n;
    for (int i = 0; i < n; i++){
        cout << (arr[i] + d) % n << " ";
    }
}
```

## Problem C

### Problem Statement

给定一个 $n \times m$ 的网格，其中部分格子中存在鱼，其余格子为障碍物。网格中有一条鱼由你控制，可以反复将它移动到相邻格子，即上、下、左、右四个方向，但不能移出网格。如果目标格子是障碍物，则可以直接移动到该格子。如果目标格子中存在一条大小严格小于当前鱼的鱼，则可以吃掉该鱼，并使自身大小增加 $1$ 。

初始时所有格子均为障碍物，接下来按顺序进行 $q$ 次操作，每次操作为以下两种类型之一：

- 给定 $x, y, v$ ，移除位置 $(x, y)$ 处的障碍物，并在该位置放置一条大小为 $v$ 的鱼。求这条鱼在由你控制的情况下最多可以吃掉多少条鱼。保证 $(x, y)$ 当前为障碍物，并且 $v$ 不小于此前放置的所有鱼的大小。

- 给定 $x, y$ ，假设在进行上述过程之前，可以将位置 $(x, y)$ 处的鱼的初始大小增加一个非负整数。设通过任意增加后的大小，这条鱼最多可以吃掉 $k$ 条鱼，求使其能够吃掉 $k$ 条鱼所需增加的最小大小。

对于以上两种操作，吃鱼过程均为假设进行，不会改变网格中已经放置的鱼的实际状态。

### Constraints

- $1 \leq n, m \leq 2.5 \times 10^5$
- $1 \leq q \leq 5 \times 10^5$
- $1 \leq v \leq 10^9$
- 其中 $n \times m \leq 2.5 \times 10^5$

### Input

输入包含多行：

- 第一行包含三个整数 $n$ 、$m$ 和 $q$ ，分别表示网格的行数、列数以及操作次数。
- 接下来 $q$ 行，每行描述一次操作。对于每次操作，给定经过加密的坐标 $x'$ 和 $y'$ 。设上次操作的输出为 $l$ ，对于第一次操作有 $l = 0$ ，实际坐标通过以下方式计算：

    $$
    x = x' \oplus l \quad y = y' \oplus l
    $$

    其中 $\oplus$ 表示按位异或运算，并保证 $1 \leq x \leq n$ 且 $1 \leq y \leq m$ 。

    操作分为以下两种类型：

    - `1 x' y' v`：计算实际坐标 $(x, y)$ 。移除位置 $(x, y)$ 的障碍物并在该处放置一条大小为 $v$ 的鱼，求这条鱼最多可以吃掉多少条鱼。保证 $(x, y)$ 当前为障碍物，并且 $v$ 不小于此前放置的所有鱼的大小。
    - `2 x' y'`：计算实际坐标 $(x, y)$ 。假设在进行吃鱼过程前，可以将位置 $(x, y)$ 的鱼的初始大小增加一个非负整数。设其最多可以吃掉的鱼数量为 $k$ ，求使其能够吃掉 $k$ 条鱼所需增加的最小大小。

    其中类型为 $1$ 的操作中的 $v$ 不需要进行加密。

> $n \quad m \quad q$
>
> $1 \quad x' \quad y' \quad v$
>
> $2 \quad x' \quad y'$

### Output

输出 $q$ 行，每行包含一个整数，表示对应操作的答案。

### Sample Input

```txt showLineNumbers=false
2 3 9
1 1 2 1
1 2 1 1
1 2 1 2
2 1 2
1 1 3 8
2 2 1
1 1 1 9
2 2 2
2 1 3
```

### Sample Output

```txt showLineNumbers=false
0
0
2
1
3
5
4
4
0
```

## Solution

这题的关键在于 **鱼的大小按照加入顺序单调不减** 。设当前加入的鱼大小为 $v$ ，那么此前加入的所有鱼的大小都不会超过 $v$ 。因此只要它们与当前鱼处于同一连通块中，当前鱼就能依次吃掉其中所有鱼。对于操作 $1$ ，只需要维护当前鱼所在连通块的大小，答案就是连通块大小减去当前鱼自身。

接下来考虑操作 $2$ ，这里不能只记录连通块中的最大鱼，因为当前鱼在到达更大的鱼之前，可以先吃掉沿途连通块中的其他鱼，从而不断增加自身大小。因此真正需要维护的是 **从当前连通块向外扩展时所需的最小初始大小** 。

由于鱼按照大小从小到大的顺序加入，可以把每次新加入的鱼看成一次连通块合并，并保留整个合并过程，这正是 **Kruskal 重构树** 的思想。每条鱼对应一个叶子节点，新加入的鱼作为新的根，将所有与它相邻的旧连通块连接到自己下面，这样得到的树就完整记录了每个连通块逐步扩大的过程。

设旧连通块的根为 $u$ ，其中有 $siz_u$ 条鱼，现在连接到一条大小为 $a$ 的新鱼。在吃掉这条新鱼之前，可以先吃掉连通块中除自身外的其他鱼，因此最多可以增加 $siz_u - 1$ 点大小。

设父节点对应的鱼大小为 $a$ ，那么想要继续吃掉这条鱼，初始大小 $S$ 至少需要满足：

$$
S + siz_u - 1 \geq a \quad \Rightarrow \quad S \geq a - siz_u + 1
$$

因此可以给节点 $u$ 记录一个值：

$$
val_u = a - siz_u + 1
$$

它表示从连通块 $u$ 出发继续向父节点扩展时，所需要的最小初始大小。

如果从一条鱼所在的叶子节点一路向上，那么每经过一个父节点都会产生一个这样的限制。要想最终吃掉整个连通块，初始大小必须同时满足路径上的所有限制，因此真正需要的初始大小就是这条路径上所有 $val$ 的最大值。

假设当前鱼的初始大小为 $s$ ，那么操作 $2$ 的答案就是：

$$
\max(0, \, maxVal - s)
$$

这里就体现出了为什么需要保留 **Kruskal 重构树的合并历史** 。普通并查集只能告诉我们当前有哪些鱼处于同一个连通块中，却无法记录一个连通块是如何一步步合并起来的，而操作 $2$ 恰好依赖这条合并过程中的所有限制。

由于每次加入的新鱼大小都不小于此前所有鱼，因此新鱼一定比它所连接的旧连通块中的所有鱼都大，可以直接让新鱼成为整个连通块的根。对于每个并查集节点维护三个信息即可，`fa` 表示当前父节点，`siz` 表示当前连通块中的鱼数，`val` 表示从当前节点继续向父节点扩展所需要的最小初始大小。

当新鱼与旧连通块合并时，假设旧连通块根为 $u$ ，新鱼大小为 $a$ ，可以得到新连通块的值：

$$
val_u = a - siz_u + 1
$$

对于已经存在的路径，在并查集进行路径压缩时，可以同时维护路径上的最大限制：

$$
val_u = \max(val_u, val_{fa_u})
$$

路径压缩后，$val_u$ 就表示从 $u$ 到并查集根的整条路径上的最大限制，操作 $2$ 只需要找到当前鱼所在的根并查询这个最大值即可。这样就无需显式建立重构树，也能完成树上的路径最大值查询。

由于每个格子最多放置一次鱼，每次加入鱼时只需要检查上下左右四个位置，并查集合并和路径压缩的总复杂度近似为线性，因此整体时间复杂度为 $O(nm + q \alpha(nm))$ ，空间复杂度为 $O(nm)$ ，其中 $\alpha$ 为反阿克曼函数。

## Problem L

### Problem Statement

给定一个长度为 $n$ 的字符串 $S$ 和一个长度为 $n$ 的整数序列 $a_1, a_2, \ldots, a_n$ ，以及 $q$ 次询问，每次询问给定一个字符串 $t$ 。如果一个区间 $[l,r]$ 满足 $t$ 是 $S[l, r]$ 的子串，则称该区间为一个 **好区间** 。保证至少存在一个好区间。

对于所有好区间，定义：

$$
f(l, r) = a_l + a_{l + 1} + \cdots + a_r
$$

求所有好区间中 $f(l, r)$ 的最大值，以及所有好区间的 $f(l, r)$ 之和对 $998244353$ 取模后的结果。

### Constraints

- $1\leq n\leq 10^5$
- $1\leq q\leq 3 \times 10^5$
- $-10^9\leq a_i \leq 10^9$
- 输入字符串由小写英文字母组成
- 所有询问字符串 $t$ 的总长度不超过 $3 \times 10^5$

### Input

输入包含多行：

- 第一行包含两个整数 $n$ 和 $q$ ，分别表示字符串的长度以及询问次数。
- 第二行包含一个长度为 $n$ 的字符串 $S$ 。
- 第三行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$ ，表示给定的整数序列。
- 接下来 $q$ 行，每行包含一个字符串 $t$ ，表示一次询问。

> $n \quad q$
>
> $S$
>
> $a_1 \quad a_2 \quad \ldots \quad a_n$
>
> $t_1$
>
> $t_2$
>
> $\ldots$
>
> $t_q$

### Output

输出 $q$ 行，每行包含两个整数，分别表示该次询问中所有好区间的 $f(l, r)$ 最大值，以及所有好区间的 $f(l, r)$ 之和对 $998244353$ 取模后的结果。

### Sample Input

```txt showLineNumbers=false
abbabaab
3 -1 4 -1 5 -9 2 -6
bab
aa
```

### Sample Output

## Solution

首先考虑一个询问串 $t$ ，记 $t$ 在 $S$ 中的所有位置为 $[l_1, r_1], [l_2, r_2], \ldots, [l_k, r_k]$ ，并按照左端点从小到大排列。

对于最大值，只需考虑每个位置 $[l_i, r_i]$ 对答案的贡献。由于包含 $[l_i, r_i]$ 的区间可以分别向左右延伸，因此预处理以每个位置结尾以及以每个位置开头的最大子段和，即可在 $O(1)$ 内计算出这个位置贡献的最大值：

$$
\sum_{j = l_i}^{r_i} a_j
+ \max \left(0, \, \operatorname{preMax}_{l_i - 1} \right)
+ \max \left(0, \, \operatorname{sufMax}_{r_i + 1} \right)
$$

对于权值累加和，如果直接对每个位置统计所有包含它的区间，同一个好区间可能包含多个 $t$ 的匹配位置，从而导致重复计算，因此我们需要对所有好区间进行不重不漏的划分。对于第 $i$ 次匹配，只统计满足以下条件的区间：

$$
l_{i - 1} < l \leq l_i \quad r_i \leq r \leq n
$$

这种划分方式可以将每个好区间分配给其所包含的左端点最靠前且不小于 $l$ 的匹配位置，因此每个好区间都能找到唯一对应的匹配位置，从而保证所有好区间都会被统计到，并且不会产生重复统计。

对于第 $i$ 次匹配，我们不妨令：

$$
L = l_i ​\quad R = r_i​ \quad P = l_{i − 1}​
$$

那么需要统计的区间则满足：

$$
P < l \leq L \quad R \leq r \leq n
$$

对于固定的区间 $[l, r]$ ，区间和可以拆成三部分：

$$
\sum_{j = l}^{r} a_j = \sum_{j = l}^{L - 1} a_j + \sum_{j = L}^{R} a_j + \sum_{j = R + 1}^{r} a_j
$$

中间部分 $[L, R]$ 对所有区间都相同，因此它的总贡献为：

$$
\sum_{j = L}^{R} (L - P) (n - R + 1) a_j = (L - P) (n - R + 1) \sum_{j = L}^{R} a_j
$$

对于左侧部分，位置 $j$ 满足 $P < j < L$ 时，能够覆盖它的左端点 $l$ 有 $j - P$ 个，因此总贡献为：

$$
\sum_{j = P + 1}^{L - 1} (j - P) (n - R + 1) a_j = (n - R + 1) \sum_{j = P + 1}^{L - 1} (j - P) a_j
$$

对于右侧部分，位置 $j$ 满足 $R < j \leq n$ 时，能够覆盖它的右端点 $r$ 有 $n - j + 1$ 个，因此总贡献为：

$$
\sum_{j = R + 1}^{n} (L - P) (n - j + 1) a_j = (L - P) \sum_{j = R + 1}^{n} (n - j + 1) a_j
$$

为了将这些式子都优化到 $O(1)$ ，预处理 **前缀和** 、**位置加权前缀和** 以及 **位置加权后缀和**：

$$
sum_i = \sum_{j = 1}^{i} a_j \quad preSum_i = \sum_{j = 1}^{i} j a_j \quad sufSum_i = \sum_{j = i}^{n} (n - j + 1) a_j
$$

于是中间部分可以直接通过前缀和计算：

$$
\sum_{j = L}^{R} a_j = sum_R - sum_{L - 1}
$$

左侧部分可以通过位置加权前缀和化简为：

$$
\sum_{j = P + 1}^{L - 1} (j - P) a_j
= \sum_{j = P + 1}^{L - 1} j a_j - P \sum_{j = P + 1}^{L - 1} a_j
= preSum_{L - 1} - preSum_P - P (sum_{L - 1} - sum_P)
$$

右侧部分则可以直接由位置加权后缀和得到：

$$
\sum_{j = R + 1}^{n} (n - j + 1) a_j = sufSum_{R + 1}
$$

这样每次匹配只需要 $O(1)$ 即可完成权值累加和的计算。如果我们对每个询问串分别在 $S$ 中寻找匹配位置，那么单个询问需要 $O(n)$ 的时间，整体复杂度将达到 $O(qn)$ ，因此需要进一步优化匹配过程。

然后考虑使用 AC 自动机优化匹配过程，将所有询问串插入 AC 自动机后，再让文本串 $S$ 在自动机上运行。需要注意的是，如果直接利用 AC 自动机扫描文本串 $S$ ，自动机的状态转移过程 **并不能覆盖所有目标串** 。

例如取 $S = \texttt{abcdabcd}$ ，目标串为 `abcd` 、`bcd` 、`cd` 、`d`，当扫描到第 $4$ 个和第 $8$ 个字符时，自动机均会转移至 `abcd` 状态，但此时 `bcd` 、`cd` 、`d` 也都在当前位置匹配成功，而自动机却无法直接转移到这些状态。

因此为了保证所有目标串都能被统计到答案中，最直接的做法是在每次状态转移后，都沿着当前状态的 `fail` 指针向上暴力访问，同时检测经过的节点是否为某个目标串的结尾，从而找到以当前位置结尾的所有目标串。

不过直接沿 `fail` 指针逐个访问所有节点仍然可能产生大量无意义的跳转，因为 `fail` 链上的节点并不一定对应某个目标串。进一步观察可以发现，我们实际上只需要关注带有结尾标记的节点，因此可以对自动机中的每个节点维护 `up` 指针，表示沿 `fail` 指针向上访问时距离当前节点最近的带有结尾标记的节点。

最后分析一下时间复杂度，对于 $S$ 中的同一个结束位置，若同时有 $k$ 个不同的目标串匹配，由于这些目标串的结束位置相同且彼此不同，它们的长度必然两两不同，因此这些目标串的总长度至少为：

$$
1 + 2 + \cdots + k = \frac{k (k + 1)}{2}
$$

设所有不同目标串的总长度为 $m$ ，可以得到：

$$
\frac{k (k + 1)}{2} \leq m
$$

由于每个位置至多对应 $O(\sqrt m)$ 个目标串，因此整个扫描过程的复杂度为 $O(m \sqrt m)$ 。又因为建立 AC 自动机的复杂度为 $O(m)$ ，预处理前缀和数组的复杂度为 $O(n)$ ，因此总时间复杂度为 $O(m + n \sqrt m + q)$ 。

## Problem H

### Problem Statement

Alice 和 Bob 进行 $k$ 轮石头剪刀布游戏，初始时二人各自持有 $3$ 张牌（包含 Rock、Scissors 或 Paper）。

胜负规则为标准规则（石头胜剪刀、剪刀胜布、布胜石头）。每轮游戏流程如下：

1. 双方可以看到彼此共 $6$ 张手牌。
2. Alice 先选择并出掉手牌中的一张牌。
3. Bob 看到 Alice 出的牌后，选择并出掉自己手牌中的一张牌。
4. 若 Alice 获胜得 $3$ 分，平局得 $1$ 分，Bob 获胜 Alice 得 $0$ 分。
5. 双方弃置已出的牌，并各自独立、等概率随机抽取一张新牌。

Alice 的目标是最大化其期望总得分，Bob 的目标是最小化 Alice 的期望总得分。

假设双方均采取最优策略，求 Alice 可以获得的最大期望总得分。

### Constraints

- $1 \leq T \leq 10^5$
- $1 \leq k \leq 10^9$
- 绝对或相对误差不超过 $10^{-6}$

### Input

输入包含多个测试用例：

- 第一行包含一个整数 $T$ ，表示测试用例的数量。

> $T$
> 
> $case_1$
> 
> $case_2$
> 
> $\ldots$
> 
> $case_T$

- 对于每个测试用例：

    - 第一行包含一个整数 $k$ ，表示游戏轮数。
    - 第二行包含一个长度为 $3$ 的字符串，表示 Alice 的初始手牌。
    - 第三行包含一个长度为 $3$ 的字符串，表示 Bob 的初始手牌。

> $k$
> 
> $Alice\_Hand$
> 
> $Bob\_Hand$

### Output

对于每组测试数据，输出一行一个实数，表示 Alice 在双方均采取最优策略下的最大期望总得分。

## Solution

本题涉及 **多轮博弈中的期望计算** ，比较适合从最后一轮开始倒推。由于最后一轮结束后不会再产生后续收益，因此可以先确定最后一轮的最优期望，再利用已经得到的结果逐轮向前推导，从而得到任意轮数下的最优期望。

首先考虑如何表示双方的手牌状态。由于每个人始终持有 $3$ 张牌，且同一种牌之间没有区别，因此手牌的具体顺序并不重要，只需要记录 Rock、Scissors、Paper 三种牌的数量即可。于是可以用一个三元组 $(r, s, p)$ 表示当前手牌，其中 $r, s, p$ 分别表示三种牌的数量，并且满足 $r + s + p = 3$ 。

根据 **隔板法** ，满足上述条件的非负整数三元组总数为：

$$
\binom{3 + 3 - 1}{3 - 1} = \binom{5}{2} = 10
$$

因此 Alice 和 Bob 各自只有 $10$ 种可能的手牌状态，双方同时考虑时一共只有 $10 \times 10 = 100$ 种状态。

定义 $f_t(x, y)$ 表示当前 Alice 的手牌状态为 $x$ ，Bob 的手牌状态为 $y$ ，还剩 $t$ 轮游戏时，在双方均采取最优策略的情况下 Alice 可以获得的最大期望总得分。当 $t = 0$ 时，游戏已经结束，不会再产生任何收益，因此有：

$$
f_0(x, y) = 0
$$

当前 Alice 首先选择一张牌 $a$ ，Bob 在看到 Alice 的选择后再选择一张牌 $b$ 。由于 Alice 希望最大化自己的期望收益，而 Bob 希望最小化 Alice 的期望收益，因此双方的决策顺序对应一个 $\max - \min$ 的过程。

若双方出牌相同，则 Alice 获得 $1$ 分；若 Alice 获胜，则获得 $3$ 分；若 Bob 获胜，则获得 $0$ 分。本轮结束后，双方出牌后分别弃掉所出的牌，且独立等概率地补充一张新牌。若 Alice 和 Bob 分别补到 $c, d$ ，则双方的手牌状态发生变化，下一轮分别转移至 $\operatorname{to}(x, a, c)$ 和 $\operatorname{to}(y, b, d)$ 。

记 Alice 出牌 $a$ 且 Bob 出牌 $b$ 时 Alice 在本轮获得的分数为 $\operatorname{score}(a, b)$ 。由于双方独立随机补牌，每个人都有 $3$ 种可能的补牌结果，因此一共有 $3 \times 3 = 9$ 种情况，并且每种情况出现的概率均为 $1 \mathbin{/} 9$ 。所以固定 Alice 的出牌 $a$ 和 Bob 的出牌 $b$ 后，当前这一轮以及剩余 $t - 1$ 轮的期望收益为：

$$
\operatorname{score}(a, b) + \frac{1}{9} \sum_{c = R, S, P} \sum_{d = R, S, P} f_{t - 1} \big(\operatorname{to}(x, a, c), \, \operatorname{to}(y, b, d) \big)
$$

由于 Alice 先行动，而 Bob 可以在看到 Alice 出牌后再进行选择，因此 Alice 在真正出牌前会预判每种选择 $a$ 在 Bob 最优应对下的最坏结果，并从中选择收益最大的方案。因此状态转移为：

$$
f_t(x, y) = \max_a \min_b \left[\operatorname{score}(a, b) + \frac{1}{9} \sum_{c = R, S, P} \sum_{d = R, S, P} f_{t - 1} \big(\operatorname{to}(x, a, c), \, \operatorname{to}(y, b, d) \big) \right]
$$

其中 $a$ 和 $b$ 必须是当前手牌中存在的牌。

由此我们可以从 $f_0$ 开始逐层递推，但题目中的 $k$ 最大可以达到 $10^9$ ，显然无法直接计算到第 $k$ 轮，因此还需要进一步观察随着轮数增加，DP 值之间的变化规律。定义相邻两轮的期望总得分之差为：

$$
d_t(x, y) = f_t(x, y) - f_{t - 1}(x, y)
$$

随着游戏轮数不断增加，初始手牌对后续状态的影响会 **逐渐减弱** ，而每轮游戏结束后双方都会通过随机补牌进入新的状态，因此经过足够多轮之后，每增加一轮游戏所带来的期望收益会 **逐渐趋于稳定** 。

也就是说，对于固定的状态 $(x, y)$ ，当 $t$ 足够大时，$f_t(x, y)$ 可以近似看成关于 $t$ 的一次函数，此时相邻两轮之间的差值也会趋于一个稳定值。因此可以先通过上述 DP 计算前 $N$ 轮，再使用最后两轮之间的差值作为之后每轮的期望增量。对于 $k > N$ 的情况，可以估计为：

$$
f_k(x, y) \approx f_N(x, y) + (k - N) \big(f_N(x, y) - f_{N - 1}(x, y) \big)
$$

对于本题可以取 $N = 1000$ ，因此先精确计算 $f_0, f_1, \ldots, f_{1000}$ 。对于 $k \leq 1000$ 的情况，可以直接使用 DP 得到答案；对于 $k > 1000$ 的情况，则使用公式进行线性外推：

$$
f_{1000}(x, y) + (k - 1000) \big(f_{1000}(x, y) - f_{999}(x, y) \big)
$$

由于双方的手牌组合共有 $100$ 个状态，每一轮的每个状态最多枚举 $3 \times 3$ 种出牌组合以及 $3 \times 3$ 种补牌结果，因此预处理 $1000$ 轮的时间复杂度为 $O(1000 \times 10^2 \times 3^2 \times 3^2)$ 。每组测试数据只需要 $O(1)$ 的时间，因此总时间复杂度为 $O(1000 \times 10^2 \times 3^2 \times 3^2 + T)$ ，空间复杂度为 $O(1000 \times 10^2)$ 。
